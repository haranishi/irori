## 問題の一覧（深刻度つき）

### 中

1. **フォーカスと主ボタンの見分け（04〜08）**：フォーカス中のボタンは、04〜07ではクリームの塗り＋輪、08（共有）では輪だけ。塗りが「主ボタン」の印か「選択中」の印か、画面から読めない。十字キーで移して塗りと輪が別のボタンに分かれると、どれが選ばれているか迷う恐れがある（動きは未確認）→ 選択中は「輪＋光」に一本化し、塗りは主ボタンだけの印と決める。08も同じ規則にそろえる
2. **右列の大きな空き（01・02・03・13・14、両幅）**：「スマホで参加」「満員です（8/8人）」「この画面からは参加できません」の見出しとQRの間が、1920で約160〜290px空く。見出しが浮き、右列が上下に割れて見える → 見出しと補足をQRの直上に寄せて1つのまとまりにし、空きはパネル上部に回す（QRの右下の位置は変えない）
3. **10の本文の折返しと書式**：「…約77分後に、自動でもう／一度試します」で「もう一度」が割れ、2行目が短く残る（両幅）。本文だけ太字の白で、文末の「。」も無い → 2文に分ける（例「今日作れる部屋の数が上限に達しました。約77分後に自動でもう一度試します。」）か文節で改行を固定し、書式を09・11・12の本文に合わせる
4. **02の待ちの文言**：参加者1人のとき「あと1人そろうと始められます」とだけ出る。棚の3本は「1〜8人」ですぐ遊べるのに、03にある選び方の案内（［決定］／［Enter］）が出ない。15秒で始める目標に響く → 「連打レースは、あと1人で始められます。ほかのゲームは、たろうさんのスマホで選べます」のように、対象のゲーム名と選び直し方を足す
5. **主役カードの題名の位置ずれ（01・02と03・13）**：中身を縦の中央に寄せているので、「あと1人で遊べます」の行の有無で題名が約30px上下する。棚を順に送ると題名が跳ねて見える恐れ → 題名をカード上端に固定し、増減する行は下に足す

### 低

6. 操作の案内が画面でまちまち：05・06には「もどる／閉じる：スマホの［戻る］か［Esc］」があるが、04・07・08には無い → 07に「選ぶ：スマホの［決定］か［Enter］」、04・08に閉じ方を1行足す
7. 「参加を締め切る」の無効表示（01・14）：参加者0人のときは枠が点線になるだけで、文字の明るさは有効時と同じ。点線は03の切断中の参加者にも使われ、意味が2つになっている → 無効時は文字を淡くするか、0人のときは出さない
8. 1366の小さい文字：「アプリもアカウントも要りません」「irori.example/pad で、このコードを入力」「記録」が約15〜16px（1080p換算で約21〜22px）で、目安の24pxを少し下回る → 1366でも1080p換算24px相当まで上げる
9. 14の警告が3か所で重複（右列の見出し・橙の枠・手順1）。手順1は4行に細切れ。主役カードの「あと1人で遊べます」は、誰も参加できない状況と食い違う → 手順1は「右の警告を見てください」程度に縮め、14では不足人数の表示を出さない
10. 14の部屋のコード（「S3BW」「CPN6」）は灰色で、地との比が約2.5:1。使えない状態なので意図的と見るが、読めても使えない文字が残る → 隠すか「開き直すと表示されます」に置き換える
11. 13の暗い青の星（さくら）は地との比が約3:1でぎりぎり → 星に明るい縁を足す
12. 01では「あと◯人で遊べます」が1画面に5回並ぶ（主役カード＋棚4枚）→ 棚は「1〜8人」表記にそろえ、不足人数は主役カードだけに出す
13. 棚4枚の右端が、主役カードの右端より約220px手前で止まり、右の揃えの線が通らない（01〜03・13・14）→ カード幅を広げて右端を揃えるか、意図した余白として残す
14. 05のプレビューは枠の中で上下に暗い帯が出て、枠と中身の地の色が違う。プレビュー内の文字は約15px以下で、遠くから読めない（図なので影響は小）→ プレビューを枠いっぱいに合わせる
15. 05の「作者・ライセンス・素材」が、操作説明と同じ大きさと明るさ → 一段小さく淡くする
16. 12の題名は「別のタブで開かれました」、本文は「別のタブか別の機器」で、範囲がずれる → 題名を「ほかの画面で開かれました」に
17. 04はダイアログの幅に対して中身とボタンが左に寄り、右に大きな空きがある → 幅を詰める
18. ヘッダーの「音：クリックで開始」は、スマホやキーボードで操作する場面では「クリック」が合わない。「ライセンスとクレジット」は主操作と同じ列にあり、目立ちすぎる → 文言を「音：押すと鳴ります」などに。リンクは一段小さく
19. 07は結果の表だけで、1位を祝う演出が静止画では見えない（動き・音は未確認）
20. 09の「つなぎ直しています」に進み具合（残り秒数や回転表示）が静止画では見えない（動きは未確認）
21. 13の満員時のQRは薄くしてあるが、薄くても読み取れるかもしれない。読めた人に何が出るかは、この画像からは分からない（未確認）
