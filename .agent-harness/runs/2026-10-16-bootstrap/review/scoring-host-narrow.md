## 問題の一覧（気づいたものすべて）

### 深刻度：高
- なし。ただし、参加の宛先「127.0.0.1」が本番でも出るなら高（「撮影の疑い」を参照）

### 深刻度：中
1. **参加の導線と参加者一覧がページの最下部**（01・02・03とそれぞれの-full）。縦2,038pxのうち、はじめかたは約1,160px、QRと部屋コードは約1,400px以降、参加者一覧も2画面目以降。最初の画面には、下にあるという手がかりもない → この幅では参加パネルを主役カードの直下へ移す（置き場所は1か所のまま）。または「あと1人で遊べます」の横に「参加のQRへ」の移動リンクを置く
2. **語の途中で折れる・最終行が1〜3字だけ**（ほぼ全画面）。01「45／秒」（数字と単位が離れる）、03-full「ぴょ／ん」、04「戻れま／す」「くだ／さい」、05「たた／いて」と最終行「得点。」、08「投／稿」、09「戻／らない」「確／かめて」、10「達しま／した」、11「使え／る」、12「開かれ／ています」 → 文節の切れ目でだけ折り返す。窓の短い文は、改行の位置を決めて入れる
3. **部品の輪郭が薄い**（目視の推定でおおよそ1.5〜2:1、基準は3:1）。01上部の「音 オン」「ロック」「共有」、02・03の棚カードの枠、06のメニュー項目、07の2位・3位の行 → 枠線を背景比3:1以上の明るさにする。実測での確認をすすめる
4. **作り手向けの文言が、遊ぶ人に見える**。10「自分のパソコンやLANの中でも動かせます（docs/operate.md）」はファイルの名前そのままで、押せるようにも見えない。03の説明「SDKの全体像を30秒で見せる、いちばん小さな見本」も同じ → 10は「自分のパソコンでも動かせます（やり方を見る）」という押せるリンクに。03は遊び方の説明に差し替える
5. **ゲームを始める操作が分からない**（03）。「OK 決定で えらぶ」の「OK」は押せるボタンに見えるが、押す場所がない。どの端末の「決定」かも書いていない → 「スマホの［決定］でえらぶ」と端末を書く。札は、ボタンに見えない形（枠のない小さな表記）にする

### 深刻度：低
6. 選択中の棚カードの拡大で列の外へ出る（01-full左上、02-full右下、03-full右上。隙間は約4〜5px）→ 拡大せず光の輪だけで示すか、列の内側に収まる倍率にする
7. 棚の左右の端が、主役カードや音の案内枠より約8px内側（01・02・03の-full）→ 同じ端に揃える
8. 参加パネルがページの下端に接している（01・02・03・12の-full）→ 下に24px以上の余白を取る
9. メニューの文字の左端が、アイコンの有無で2本に分かれる（06）→ アイコンのない項目にも同じ幅の空きを取る
10. 表記ゆれ。ホームは「音 オン」「ロック」、メニューは「音：オン」「ロック：オフ」（01・06）→ どちらかに揃える。「ロック」は何を止めるかが分かる名前（例：「参加を締め切る」）にする
11. 「音 オン」が今の状態なのか、押す操作なのか分からない（01）。同じ画面の「音を出すには、この画面をクリック」の案内とも食い違って見える
12. 音の案内がタッチ操作に合わない（01「クリックするか、キーを押してください」）→ この幅では「画面をタップすると音が出ます」
13. エラー画面では音の案内が上端の光る帯になり、エラーの窓と注意を取り合う（09・10・11）。ホームの破線の枠とも形が違う → エラーの表示中は出さないか、ホームと同じ部品に揃える
14. エラー画面の組み方が2種類（09・12は左揃えでロゴなし、10・11は中央揃えでロゴあり）→ 部屋の有無で分ける意図ならその規則を守り、そうでなければ1つに揃える
15. 「あとで試す」（10）は、今押すと何が起きるのかが分からない → 「閉じる」など、押した結果が分かる言葉にする
16. 結果の「800」に単位がなく、「0.9秒」が何の時間かも分からない（07）→「800点」「ゴール 0.9秒」
17. 結果のボタンのうち「共有」だけが2行目に落ちる（07）→ 3つを縦1列に並べるか、「共有」を小さなアイコンのボタンにして1行に収める
18. 取り消しにくい「外す」が明るい塗りで一番目立つ（04）。最初の選択が「やめる」なのは良い → 「やめる」を塗りの主ボタンに、「外す」を枠だけのボタンにする
19. 主役カードのプレビューは上下の黒帯が大きく、中の文字は約7pxで読めない（01・02・03）→ 枠いっぱいに合わせるか、文字のない絵にする
20. 「つながっていません」（03-full）の灰色は目視でおおよそ4:1前後で、本文の基準4.5:1を下回る見込み → 少し明るくする
21. 補足の文字が約13pxと小さい（01-full「127.0.0.1…で、このコードを入力」、10「docs/operate.md」、01「ライセンスとクレジット」）。リンクは押せる範囲も狭い → 14〜16px以上にする
22. 上部の3ボタンの高さが約42pxで、スマホのボタンの目安48pxに届かない（01）→ この幅では48pxにする
23. 主役カードに作者とライセンスが常に出ていて、「あと1人で遊べます」が下へ押される（01〜03）→ 狭い幅では詳細の窓（05）に任せる
24. 「ほかの画面で開かれました」（12）の選択肢が「ここで続ける」だけ → 「このタブを閉じる」も置く

## 撮影の疑い
- 04・05・12の-full：暗い幕が上の約840pxで止まり、その下は明るいまま。固定された幕を縦長に撮ったためと考え、採点には使っていない
- 01〜05と12の-fullにある参加パネル、08の共有欄の宛先が「127.0.0.1:8819」。開いている端末自身を指す宛先で、ほかのスマホからは開けない。開発環境で撮ったためだろう。本番でもこの表示なら深刻度は高
- 08：スマホの幅なのに、端末の共有画面を開くボタンがない。撮影に使ったブラウザでは出ないだけかもしれない
- 06：一時停止の後ろのゲーム画面がほぼ真っ黒。暗くする演出なのか、描画の前に撮ったのかは判断できない
- 01・02・12の主役のプレビューが灰色なのは、まだ遊べない状態の表示と判断した（02-fullの棚では、遊べるゲームだけ色付き）
