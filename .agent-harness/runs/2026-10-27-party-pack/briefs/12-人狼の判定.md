# 担当C3：人狼（月夜の村）の判定（Codex）

`00-共通の約束.md` を先に読む。そのあと `.kiro/specs/party-game-pack/game-werewolf.md` と、`requirements.md` の要件 10・4・5 を読む。

## 所有する場所（これだけを書く）
`games/moon-village/logic.js`、`games/moon-village/roles.js`、`games/moon-village/logic.test.js`、`games/moon-village/roles.test.js`、`games/moon-village/balance.test.js`、`tools/mutations/specs/party-pack-moon-village.json`（変異の仕様。形は `tools/mutations/specs/competitive-pack.json`）、`reports/人狼の判定.md`。タスクは2つ（2.3：配役・夜・夜明け・秘匿、2.4：昼・投票・勝敗・退出）。同じ担当が順に作る。画面は別の担当が作る。作らない。

## 作るもの
- `roles.js`：`makeRng(seed)`、`rolesFor(n)`（設計書の表。4〜8人）、`assignRoles(seatIds, seed)`（全員に1つ）。役は `villager` `wolf` `seer` `knight` `madman`。
- `logic.js`：`createGame(init)`・`updateGame(state, event)`・`publicView(state)`。`init` は `{players, leader, environment, paused, nonce, seed, discussMs}`（議論の既定は180000ms）。イベントは `input`（`k:'btn'` の開始、`k:'tiles'`）・`players`・`menu`・`environment`・`tick`（`{t:'tick', ms}`＝止まっていない間に経った時間。主役の時計はこれだけで進める）。効果は `{t:'pad', to, spec}`・`{t:'cue', name, v?}`・`{t:'vibrate', to, ms}`・`{t:'end', results, options}`。
- 段階は設計書のとおり：`intro` → `reveal` → `night` → `dawn` → `day` → `vote`（→決選）→ `exec` → `ended`。止めるべきとき（一時停止・生きている席の接続切れ・画面の非表示）は、`blockers` で時計を止める。手本は `games/lantern-market/logic.js` の `blockers` と `reconcile`。
- スマホの画面は設計書の節「進行」のとおり。夜は、生きている全員に同じ形の `tiles`（`max` 1・`ok`「決定」・`pass`「役を見る」）。`note` の文面は全役職で同じ。役ごとの `off` は付けない。選べない相手を選んだら「行動なし」とし、夜明けに本人にだけ `wait` で理由を伝える。識別子は `w{nonce}_{改訂番号}_{席}`。
- `publicView`：`{phase, day, seats:[{id,name,alive,left,online}], announce, timer:{remaining,total}|null, decided:{count,total}|null, votes:[{from,to}]|null(公開後のみ), reveal:[{id,role}]|null(終了後のみ), leader, canBegin, outcome}`。**終了前は役職を一切含めない。**
- 効果音：夜 `night`、夜明け `dawn`、投票の開始 `vote`、公開 `reveal`、処刑 `execute`、勝敗 `win` / `lose`。
- 結果は設計書のとおり（勝った側 `score` 1・`display: 'record'`・`label`「人狼・勝ち」など。席が消えた人は `ranked: false`）。
- あいまいな点（人狼どうしの票が割れたとき、守りと占いの重なり、ちょうど同数の勝敗など）は、設計書に最も近い解釈にし、報告の④に書く。

## 試験で守るもの
①配役の内訳と再現、全員に1つ ②夜明けの解決の全組合せ（守り成功・襲撃なし・票が割れた・初日・連続の守り・占いが狂人を見た） ③勝敗の判定を全局面で（人狼0人、人狼数が人間数以上、狂人は人間として数える） ④決選・棄権・時間切れ（夜と投票は、決定が2分止まったとき。議論の時計は既定180秒） ⑤秘匿：どの席宛の `pad` にも、設計書の「許される開示」の表にない他席の役が入らない（人狼どうし・占い師の結果・終了後だけ許す）。`publicView` に終了前は役職が無い（全局面を走査）。夜の `pad` の形（`k` と `note` と `ok` と `pass`）が全役職で同一 ⑥席の消失・接続切れ・一時停止・`end` が1回 ⑦`balance.test.js`：人数ごとの無作為な対戦を各2000回。無作為な村側で人狼側の勝率が5〜95%、占い結果を使う村側で村人側の勝率が40%以上。変異を `party-pack-moon-village.json` に書き、`npm run mutations` の実行器で全部赤くなることを確かめて報告に書く。 型検査（`npm run typecheck:games`）は、`tiles` の型が SDK に入るまで通らない。通らないときは報告に書くだけでよい。
