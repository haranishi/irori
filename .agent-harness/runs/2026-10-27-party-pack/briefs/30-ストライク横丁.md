# 担当D：ストライク横丁（ボウリング）（Opus）

`00-共通の約束.md` を先に読む。そのあと `.kiro/specs/party-game-pack/game-bowling.md`（規則・物理・得点・進行・手触り）と、`requirements.md` の要件 7・5・6 を読む。この担当は、純粋部品（タスク2.5の得点と指の読み取り、2.6の物理）と、進行・画面・登録（タスク4.1）を、この順に作る。

## 所有する場所
`games/strike-alley/**`（`irori.js`・`irori.d.ts` は同期で入る。編集しない）、`registry/games/strike-alley.json`、`tools/mutations/specs/party-pack-strike-alley.json`、`reports/ストライク横丁.md`。サムネイルは作らない。撮影の手順を報告に書く（メインが道具に足して撮る）。

## 進め方
1. **純粋部品を先に**（`scoring.js`・`gesture.js`・`physics.js` と各 `*.test.js`）。物理は、設計書の「調整の目標」を満たす数値の表に集める。まず調整用の小さな道具（例：全組を数える Node のスクリプト。リポジトリには入れず、報告に結果の表だけ貼る）で、ストライクの幅・ガター・中央の直球の本数を測り、目標に入るまで数値を直す。乱数を使わず、同じ入力は同じ出力。
2. **進行と画面**（`logic.js`・`main.js`・`view.js`・`index.html`・`style.css`・`README.md`）。`logic.js` は `createGame`/`updateGame`/`publicView` の形（手本は `games/lantern-market/`）。画面は DOM と Canvas のどちらでもよいが、依存は足さない。遠近のレーンは、固定のカメラ＋ボールが進むと寄る動き。再生は、物理が返した `frames`（60Hz）を、時間で補間する（描画の速さで結果が変わらない）。
3. **手触り**：重ね方は設計書の「大画面と手触り」のとおり。小さな反応を5〜8個重ね、重要度（通常の本数／スペア／ストライク）で強さを変える。揺れは減衰する値で、毎フレームの乱数にしない。静止は実時間で測り、重ならないように最新の呼び出しだけが戻す。動きを減らす設定では揺れ・静止・舞いをやめる。
4. **効果音**：`irori.cue(name, v)` を、`irori.cue?.(...)` のように守りつきで呼ぶ（この時点の SDK にはまだ無い。あとで入る）。名前は `roll` `pins` `strike` `spare` `gutter`。投げた人のスマホに `irori.vibrate`。
5. **段階名**：`document.documentElement.dataset.phase` に判定の段階名（`intro` `aim` `rolling` `settled` `ended`）を出す。通しの試験とサムネイルの道具が読む（手本は `games/lantern-market/view.js`）。
6. **登録**：`registry/games/strike-alley.json`（手本は `registry/games/lantern-market.json`。`id` は `strike-alley`、`pads` は `["wait","touch","choices"]`、人数1〜6、`thumbnail` は `strike-alley.jpg`（メインが撮る。ファイルはまだ無くてよい））。

## ブラウザで確かめる
`npm run dev` で開発サーバーを起動し、`/games/strike-alley/?mock=3` で仮想プレイヤーを使う。Playwright で、ポインターの s→m→e を送って投げ、再生を待ち、画面を撮る（390・768・1440の3幅。縮めてから見る）。見ること：引く長さ・位置・ずれと、狙い線・強さ・曲がりの予想線が合っているか／再生が滑らかか／字幕が欠けないか／得点表が6人でも収まるか／CPUを4倍遅くしても同じ本数か／一時停止で止まるか。見つけた崩れは直し、3周まで繰り返す。撮影のスクリプトは `reports/` に置かない（リポジトリに入れない）。

## 守る数字
物理は1投あたり6秒以内の再生。`frames` は60Hz。`logic.js` と `scoring.js` は、DOM と SDK を読まない。

## 試験で守るもの
設計書の「試験」の節のとおり。特に、①得点の全パターンと満点300・5フレームの満点150 ②調整の目標（ストライクの割合5〜30%、連続する幅0.12以上、縁へ向かう曲がりで0本）③ピンが0〜10本で、一度倒れたものが立たない ④同じ入力で同じ出力 ⑤拒否（古い・他席・投げない・s のない m と e）が状態を変えない ⑥退出（残りの席で続く。2人以上で始めて残りが1人になったら未成立、1人で始めた勝負は続く）と一時停止。変異で赤くなることを確かめる（変異の仕様は `tools/mutations/specs/party-pack-strike-alley.json`）。
