# 通しの試験の下書き（Codex・ブラウザなし）：4本

`00-共通の約束.md` を先に読む。そのあと、手本として `tests/e2e/console/competitive-pack.spec.ts`・`tests/e2e/console/fixtures.ts`・`tests/e2e/console/lib/{host,pad}.ts`・`tests/e2e/console/lib/tags.ts` を読む。実ホスト・実Worker・実際のスマホ（別ブラウザ文脈）で、新しい4本を最初から最後まで通す試験を書く。**Codex はブラウザを動かせない**。書くだけで、走らせるのはメインか Opus。だから、セレクタ・待ち方は、既存の試験と各ゲームのコード（`games/<id>/{main,view}.js` の `data-` 属性・`dataset.phase`）を読んで、確実なものだけを使う。文言には頼らない。

## 所有する場所
`tests/e2e/console/party-pack.spec.ts`（新規）と、`tests/e2e/console/lib/pad.ts` への道具の追加（`tiles()`・`swipe()` など。既存の道具は変えない）。ほかは編集しない。

## 書くもの（各ゲーム1〜3本。タグは `HOST`＝Chromium と WebKit、手本のとおり）
1. **共通の道具**：`Pad.tiles(ids|'first'|{pass:true})`（`.irori-pad[data-kind="tiles"]` の札を選んで決定／パス。選べる札の `data-id` を読む）、`Pad.swipe(x0,y0,x1,y1,ms)`（`.irori-pad__touch` の枠の中の0〜1の座標で、実物のタッチの s→m→e を送る。`tools/playtest-server.mjs` の `swipe` が手本）、`Pad.receivedFrames()` で、そのスマホが受け取った `pad` フレームの `spec` を全部読めること（既にあれば使う）。
2. **秘匿の走査**：どの場面でも、各スマホが受け取った `pad` フレームを全部集め、他席の秘密が入っていないことを確かめる関数。大富豪＝他席の手札の札の `label`／`id`、ババ抜き＝他席の手札と、引いた札の中身、人狼＝設計書の「許される開示」の表にない他席の役職の語（`村人` `人狼` `占い師` `騎士` `狂人` を、自席の役と、人狼どうし・占い師の結果・終了後を除いて含まない）。共用画面（ホストのゲームの枠）の `body` にも、同じ語が終了前に出ないことを確かめる。
3. **ストライク横丁**：2台。開始→モード選択（短い5フレーム）→番の人が `swipe` で投げる→`rolling`→`settled`→次の席。**1人で始めた5フレームを、ストライクの投げ方で最後まで通し**（`host.advance` で時計を進める）、結果の合計が150になり、「もう一度」で `intro` に戻ること。ストライクの投げ方は `reports/ストライク横丁.md` の「サムネイルの撮影の手順」の投げ方（hook 0.6・強さ0.7）を、枠の座標に直して使う。途中の退出・切断・再接続・一時停止も1本。
4. **大富豪**：まず2台で選び、人数不足で始まらず、あと何人必要かが出ること（要件1.2）。4台で開始→数回の出す（選べる札のうち、最も弱い札を1枚。番が替わるたびに、いまの番の席を `host` の公開データか `expectPhase` で確かめる）→パス→革命または8切りは、種を固定できないので試験しない（単体試験が持つ）。途中の秘匿の走査。2人が退出して未成立（順位なし）の結果になること、「もう一度」で配札が変わること。旧ホスト（能力なし）の更新案内は、`games/daifugo/main.js` の `unsupported` 分岐を読んで、可能なら1本。
5. **ババ抜き**：3台。配札→各番「引く人の先頭の札」を引く→ゲームが終わるまで繰り返し（番の数が多いので `expect.poll` で `phase` を見る）→結果（最下位が1人）→再戦。秘匿の走査。切断→再接続で `tiles` の画面が戻ること。
6. **月夜の村**：4〜5台。役の確認（全員「役を見る」→「かくす」）→夜（全員が選んで決定）→夜明け→昼（リーダーが「投票へ」）→投票（全員が先頭の相手に）→処刑→勝敗が決まるまで繰り返し→結果（全員の役が表になる）→再戦。**夜の画面の形（札の数・`ok`・`pass` の有無）が全スマホで同一**であること。秘匿の走査（許可表を使う）。再接続で画面が戻ること。

## 守ること
- 待ちは `expect.poll`／`host.expectPhase` で、固定の `waitForTimeout` を避ける。時間はホストの時計（`host.advance`）で進める。
- 1本の試験が3分を超えない作りにする（超えそうなら、手を省略せず、人数・フレーム数を減らす）。
- 走らせられないので、書いた試験が `npx tsc -p tests/e2e/tsconfig.json --noEmit`（無ければ `npm run typecheck`）で型検査を通ることだけ確かめる。
- 報告（`reports/通しの試験の下書き.md`、100行以内）に、各試験が確かめること・未確認（走らせていない）の一覧・不確かなセレクタを書く。
