# 追補D1：大富豪とババ抜きの修正（独立レビューの指摘）（Codex）

`00-共通の約束.md` を先に読む。大富豪とババ抜きの前回の報告（`reports/大富豪の判定.md`・`reports/ババ抜きの判定.md`）も読み直す。

## 所有する場所
`games/daifugo/`・`games/old-maid/`（画面・試験を含む）、`tools/mutations/specs/party-pack-daifugo.json`・`party-pack-old-maid.json`、`reports/追補D1.md`。通信の型・ホスト・pad-ui は変えない（変えたくなったら報告に書く）。

## 見つかった不具合（独立したレビューが、コードと実コンポーネントで再現した）
1. **高・大富豪：同じ不正な出し方を繰り返すと、スマホが「送りました」のまま固まり、番が進まない。**
   `games/daifugo/logic.js` の `reject()` は、状態を変えずに、同じ内容の tiles 画面を返す。ホストの送信係（`apps/web/src/host/pads.ts` の `PadSender.sync`）は、前回送った画面と JSON が同じなら送らない。スマホの tiles（`packages/pad-ui/src/pad.ts` の `Tiles`）は、「出す」を押すと、次の画面が来るまで固まる。再現：場が空で、数の違う2枚を選んで「出す」→ 断り（note が変わるので届く）→ もう一度同じ操作 → 断りの画面が前回と完全に同じで送られず、固まる。
2. **中・4本とも：「はじめる」の前（`phase === 'intro'`）に全員が席を立つと、`end` が一度も送られない。** intro では `players` イベントごとに席を名簿から作り直すので、名簿が空になると席が消え、何も起きずに intro のまま残る。

## 直し方
### 大富豪（1と2）
- 1：**断るたびに、その席の画面が必ず変わる**ようにする。席ごとの「断った回数」を状態に持ち（例：`state.refused`、`{[席]: 回数}`。`createGame` で `{}`）、tiles の `token` と札の id（`cardId`）に、その席の回数を含める（例：`d{nonce}_{revision}_{回数}`）。`reject` は、その席の回数を1つ増やした新しい状態を返す。入力の `t` と ids の検査は、その席の現在の token と照らす。古い token の入力は、今までどおり黙って捨てる。**ほかの席の画面と token は、断りで変えない。** `cardId` を使う画面・試験は、席を渡す形に合わせる。
- 2：intro で名簿が空になり、それまで席があったとき：元の席を全員「退出」（`left:true`）として残し、`outcome:'incomplete'` で `end` を1回だけ送る（開始後に全員が抜けたときと同じ結果の形：全員 `ranked:false`・label「退出」）。一度も席がなかった場合は何もしない。終わったあとの `players`・入力は無視する。
### ババ抜き（2のみ）
- 同じ規則で、intro の全員退出を直す。あわせて、`updateGame` の入力の経路に「断って同じ画面を返す」道がないかを調べる。あれば大富豪と同じ直しを入れ、なければ「なし」と報告に書く。

## 試験
- 大富豪（`logic.test.js`）：①場が空で、手札の違う数の2枚を出す→ 断りの画面。**同じ操作を（そのつど新しい token・新しい札 id で）5回繰り返しても、毎回、前回と `JSON.stringify` が異なる画面が返る**。②古い token・古い札 id の入力は、状態も画面も変えない。③断りで、ほかの席の画面と token が変わらない。④断ったあとの正しい出し方が、普通に受理される。⑤既存の対戦の無作為試験・秘匿の試験が通る。
- 両方：intro で全員退出→ `end` がちょうど1回・`outcome:'incomplete'`・全員退出。そのあとの `players`/入力で2回目の `end` が出ない。最初から席が1つもない `players` では `end` が出ない。
- バグ修正の試験の名前か注釈に、「なぜ失敗したか」を書く。
- 変異（`party-pack-*.json` に足す）：「断りで回数を増やさない」「token にその席の回数を含めない」「intro の全員退出で `end` を出さない」（ババ抜きにも同様）。行が変わって既存の変異の `find` が見つからなくなったら、新しい行に合わせて直す。
