# 追補D5：ババ抜きで、途中で1人が抜けると、残りの勝負が終われない不具合（Codex）

`00-共通の約束.md` を先に読む。前回までの報告（`reports/ババ抜きの判定.md`・`追補D1.md`・`追補D3.md`）と、`.kiro/specs/party-game-pack/game-old-maid.md` も読み直す。

`games/old-maid/`（画面・試験を含む）、`tools/mutations/specs/party-pack-old-maid.json`、`.kiro/specs/party-game-pack/game-old-maid.md`（退出の規則の段落だけ。100行以内）、`reports/追補D5.md`。**`tests/e2e/` は触らない**（メインが持つ）。通信の型・ホスト・pad-ui は変えない。E2E が頼っていそうな文字（`最下位`・`ジョーカーが残った`・`記録なし`・`未成立`・`勝負が終わりました`）を変えたら、`tests/e2e/console/party-pack.spec.ts` を grep して、影響する行を報告に書く。

## 見つかった不具合（実際に遊んだ評価担当が3試合で3回再現。メイン側でも原因を読んで確かめた）
**3人で始め、途中で1人が抜けると、残った2人の勝負がいつまでも終わらない。** 60手以上進めても、手札が「4枚と5枚」を行き来するだけだった。原因：席が消えたとき、その人の手札（ジョーカー以外）を「除外」の山へ移している（`games/old-maid/logic.js` の `players` イベントの処理）。ババ抜きは、同じ数の札が偶数枚あるから、ジョーカー以外の全部がペアで捨てられる。除外すると、その相方の札が、残った人の手に「相方のいない札」として残り、二度と捨てられない。だから、残りが2人でも、手札が空になる人が出ず、終わらない。

関連して、評価担当は次も指摘した（直す）：(a) ジョーカーを持つ人が抜けてジョーカーが移った人に、理由の知らせがない。(b) 番の人のスマホに、誰の札から引くのかの見出しがない。(c) 負けた人のスマホは「あなた：JK。3位」とだけ出て、負けたと書いていない。(d) 番に関係ない人の見出し「○○さんが○○さんから札をひいています」が、名前の途中で折り返す。

## 直し方（この方針で）
1. **退出した人の手札は、手札が残っている席（上がっていない・退出していない席）へ、種つきの乱数で全部配る**（ジョーカーも含める。除外の山は使わない＝札の合計も、ペアの偶奇も保つ）。配られた席は、できたペアをすぐ捨てる（ペアは `discard` へ、`pair` の公開イベントも出す）。配られて手札が空になった席は、上がりとして順位を付ける（同時なら席番号の小さい順）。手札が残っている席が1つもないときは、配らない。
2. 配ったあと、手札が残っている席が2つ以上なら、そのまま続ける（番の再計算は今の `openTurn` のとおり）。**1つ以下なら、退出で終わる。このとき、最後に手札を持つ1人（ジョーカーだけを持つ人）には順位を付けない**（相手が抜けただけで、その人は負けていない）。上がった人が2人以上なら `outcome:'complete'` で、上がった順位はそのまま。2人未満なら `outcome:'incomplete'` で、全員順位なし。
3. 結果の `end`：順位を付けない席（退出した席・最後に残った1人）は `ranked:false`、`score:0`。label は、退出した席は「記録なし」、最後に残った1人は「勝負なし」、上がった人は今のとおり（`n番目に上がり`）、普通の終わりの最下位は今のとおり（`ジョーカーが残った`）。**普通の終わり（誰も退出していない）の結果は、今のまま変えない。**
4. スマホ：(a) 配られた席のスマホに、次の操作までの間、「退出した人の札が{n}枚、配られました」を出す（`wait` の title か `tiles` の `note` の先頭）。配られた札の中身は、その席の手札の文にだけ出る。ほかの席・大画面には、枚数以外（ジョーカーの行き先を含む）を出さない。(b) 引く番の人の `note` の先頭に「{引かれる人の名前（12文字まで）}さんの札（{n}枚）から1枚えらぶ」を足す。(c) 負けた人（ジョーカーが残った）の終了後の本文を「あなた：JK。ジョーカーが残りました」の形にする（`n位` だけにしない）。(d) 番に関係ない人の `wait` は、title を「札をひいています」にし、body を「{引く人}さんが{引かれる人}さんから」＋改行＋手札の文にする（名前は各4文字まで。title に名前を入れない）。
5. 退出で `end` に入るときも、いまの「退出していない全席へ最終の `wait` を送る」処理は保つ（本文は、順位なし・勝負なし・退出の別が分かる文にする）。

## 試験（`logic.test.js` など。バグ修正の試験には「なぜ失敗したか」を書く）
- **再現を先に赤にする**：3人で始め、1人が上がったあと（または上がる前）、残る2人のうち1人が抜ける。直す前は終わらない・直した後は終わる、を確かめる。
- **退出を混ぜた無作為な対戦**：2〜8人×各2000回（既定は300回でよい。`IRORI_SIM_GAMES` の仕組みに合わせる）で、毎回、ランダムな時点でランダムな席が抜ける（連続して抜ける・上がった人が抜ける・ジョーカーを持つ人が抜ける・番の席が抜ける、を含む）。最後まで、一定の手数（例：5000手）以内に必ず終わる。毎手、札の合計が53枚で重複がない。終わったとき、手札を持つのは1人以下で、持つ人はジョーカーだけを持つ。`end` はちょうど1回。順位は1から連番で、重複しない。**退出した席・最後に残った1人には順位がない。**
- 上の2の分岐（上がった人が2人以上／1人／0人）の例を、それぞれ1つずつ。
- 秘匿：新しい文（配られた知らせ・見出し）に、他席の手札の中身・ジョーカーの場所が入らない（既存の秘匿の試験が通る）。
- 変異（`party-pack-old-maid.json`）：「退出した手札を除外へ戻す」「最後に残った1人に順位を付ける」「配った後にペアを捨てない」「配られた知らせにジョーカーの有無を入れる」を足す。行が変わって既存の変異の `find` が見つからなくなったら、新しい行に合わせて直す。全部赤（killed）になること。
