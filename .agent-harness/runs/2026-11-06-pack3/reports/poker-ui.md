# 担当B：poker-ui

## 実装したこと
- 判定の席別pad・公開ビュー・end効果をSDKへ接続。終了の行を加工せず `irori.end(e.results,e.options)` へ渡す。
- CPUは局の開始時に固定。席別の種つき乱数と本人padを使って予約し、発火時の最新ビューから通常入力を送る。
- 同じ本人padの予定は維持し、変更・停止・切断・非表示・終了・ページ破棄で取り消す。
- SDKのpad・look・endは人だけ。人1＋CPU3、人数充足時の補充なし、CPUだけの連続デモに対応。
- 木・生成り・柿色の卓、席の輪・親・CPU図形・番・手札公開・役・勝者・時間・直近4件・全席の順位を描画。
- 札の柄と数は自作SVG。公開ビューだけを描き、勝負前の手札をDOMへ置かない。文字はtextContentで挿入。
- 8席の勝負画像で隣席の接触と下の出来事への重なりを発見し、札の高さと席の位置を調整した。
- README（53行）に遊び方・役・人数・長さ・持ち点限定・CPU・権利を記載。登録と640×480 JPEGを追加。
- サムネイルはゲームのデモから撮影。説明・名札などの文字を非表示にし、札の自作図形だけを残した。
