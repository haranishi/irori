# V2：新作2本の暫定イメージ動画

- 対象は `bell-in-sleeve`・`poker`。撮影時点の作業ツリーから配信した大画面のみを録画した。
- ゲーム側は別担当が仕上げ中。2本とも暫定版で、仕上げ後に下記の台本で撮り直す。
- 外部素材・音・字幕・生成映像は追加していない。ゲームのモデル・秘密情報・時計・勝敗は操作していない。

## 撮影元と区間

- 2本とも `demo=1` と `mock=4` の画面を比較し、入力待ちが短い仮想パッド操作を選んだ。
- 鈴は全種類が配られる6席の `mock=6`。有効な札から未撮影の効果を優先し、相手・位置は種つき操作で選ぶ。
- のぞき見・すりかえ・ひそひそ話・かばう・つかまえるの初回操作から各1.6秒を時系列で残す。
- 結果2.5秒を最後に追加。必要な札が出ない局はエラーとして採用しない。区間は重複させない。
- ポーカーは `mock=4`。最初の1回だけふやし、その後はあわせる・そのままを選ぶ。
- 同じハンドの配札から勝者まで連続区間を残す。途中は切らず、手札公開と勝者を約3秒読む。
- 操作の乱数の種は共通道具の20261106。ゲームの配札は変更しないため手札・勝者は毎回変わりうる。
- 最初の動きを探す既存処理と両端0.5秒の重ね合わせを使う。途中は実時間のまま、静止の待機だけ省いた。

## 再撮影の手順

1. ゲーム仕上げ後、`nice -n 10 timeout 3000 env IRORI_DEV_PORT=8834 node tools/dev.mjs` で起動し直す。
2. 別の端末で、上記撮影コマンドの `<id>` を `bell-in-sleeve` と `poker` にして1本ずつ実行。
3. `--verify-only`、9コマ・継ぎ目の目視、`npm run prepare:web`、`npm run check` を実施。
4. サーバーを終了する。道具は専用文脈を閉じ、旧版は `.probe-tmp/previews/_backup/` へ退避して置換する。
