# 第3弾：PR前の権利・規約・法律の確認（2026-11-06）

運営者の指示（2026-10-12：PRを作るときは、著作権・規約・法律を、しっかり調べ、駄目なら直す）に沿って、`main`（4be25c7）との差分230ファイルを確かめた。「調べていない」は「問題なし」と書かない。

## 方法
1. **機械の検査**：`npm run check`（権利・依存・文書・登録・SDKの同期）。禁止語・音声と書体のファイル・私的なパス・外部の読み込みを拒む。ただし、動画や画像の中身は見ない。
2. **追加した行の走査**：私的な情報（絶対パス・内部のアドレス・メール・鍵）、賭け事を連想させる言葉、実在の作品・ブランド名、外部のアドレス、依存の変更、新しい画像・動画。すべて問題なし（賭け事の言葉は、使わないと書いた説明の中だけ）。
3. **独立した読み取り専用の調査**（別のAI。Web検索可。コードを書き換えない）：コードの出どころ、札の名前・文章・図柄・構成と非公開の調査メモ（商用作品との比較）、動画・サムネイルの写り込み、依存とライセンス、13本の名前、ポーカーと景品表示法・賭博罪・資金決済法、外部送信、ホーム画面と不正競争防止法。
4. **動画の文字の書体**：運営者の方針（`docs/legal/rights-check.md`）と動画の撮り方を照らして、親（メイン）が見つけた（下の4）。

## 問題なしとした項目（根拠）
- 推理カード：札の名前・効果・文章・図柄は、非公開の調査メモの商用作品の写しではない。6種類の札・人数別の枚数・同時開示・最後の一斉指名・得点が実装され、名前・文・絵は自作。札・猫・鈴は、コードで描いた図形。
- ポーカー：全席1000点で始まり、購入・課金・換金・景品・外部への送金の経路がない。画面と文言は「点」「たまり」で、賭け事の言葉を使わない。景品表示法・賭博罪・資金決済法に触れる接続は、見つからなかった（運営者が別に賞金・景品・参加料を結び付ける運用は、この判定に含まない）。
- 動画・サムネイル：動画13本から4つの時点のコマを抜き出し、サムネイル13枚とあわせて見た。他社のロゴ・人物・連絡先・個人情報は写っていない。表示名は「プレイヤー」「CPU」など。動画は音声なし（`ffprobe`）。ゲームの音は、コンソールの合成音。
- 依存：`package.json`・`package-lock.json` の差分なし。配布物に入る依存は `qrcode-generator`（MIT）だけ。新しい書体・画像・音のファイルは、リポジトリに入れていない。
- 新しい外部送信：ホームと新作の差分に、解析・広告・第三者への送信は見つからなかった。動画の読み込みは、同じオリジンだけ。
- 全年齢：性的・残虐な表現、実金銭への誘導は見つからなかった（`rating: all` は自己申告）。

## 残る共通点（直していない）
- ホームの格子は、幅1024pxで4列×3行。家庭用ゲーム機のホーム画面にも4×3の構成があり、この点は共通する。違いは、列数が幅で2〜6に変わること、箱が3:2・角丸28px、暗色と暖色、左下の小さなQRカード、上の道具、名前の帯、箱に文字を出さないこと。格子の配置だけで侵害になるとは判断しない（形態の模倣には、依拠性と実質的な同一性が要る）が、最後の画面の全状態・動き・音を並べた比較は、していない。

## 確かめていないこと

- 関連する意匠・特許と、最後のホーム画面の全状態・動きの比較。
- 新作コードの実際の参照元・制作経緯の全体、商用の非公開コードを含む網羅的な複製の照合。
- 参考にした作品の全札面・説明書・各版との、全面的な比較。
- 撮り直した動画の全コマの検査（抜き取りだけ）。公開環境の実際の通信・ホスティングの設定。Xの現行の規約。外部送信の規律（電気通信事業法27条の12）の適用の判断。
