# ブリーフ：第3弾（ホームの作り直し・動画・CPU・推理カード1本）

## 依頼（2026-11-06・音声入力・追記の順）
- 既存の遊びを irori に足したい。著作権と法律に引っかからないかを先に確かめる。本人の見立ては「規則そのものに著作権はない。画面や絵に著作権がかかるので、そこを変えればよい。ダメなら調整して」。
- ゲームを増やす、または既存のゲームの質を上げる。スキルとハーネスを使い、実装はサブエージェント（Codexなど）で進める。質問があれば知らせる。
- 先に、いまの画面を見たい（手元で11本を起動して見てもらった）。
- 画像でなく、各ゲームの「遊んでいる雰囲気」が伝わる動画を作る（Codex を使う）。
- 1人のときや人数が足りないときは CPU を加える（そうしないと試せない）。
- ホーム画面を、家庭用ゲーム機のように箱が並んで選べる形にする。箱ごとに動画が流れ、タイトルはタップで出す。タイトルは分かりやすく。QRは下に出し、タップで大きく。丸写しは避け、色などを変える。

## 方針
- 順番：①権利の確認（読み取り）②ホームの作り直しの見た目と操作（M1）③動画の道具と全11本の動画 ④CPU（新作から、既存の札・対戦ゲームへ）⑤推理カード「ふところの鈴」⑥通しの試験と採点 ⑦ポーカー（お金・景品なし、持ち点だけ。本人の確認済み・2026-11-06。CPUつき。全年齢向けのまま、賭けの演出は入れない）。
- 規則の骨格は借りてよい。名前・絵・文・ルールブックの言い回し・世界観・音は借りない。札の構成（種類・枚数・効果の対応）は、市販品と1対1にしない。
- ホームは、参考にした画面の骨組み（箱の格子・選ぶと名前・下の帯）だけを借り、色・形・動き・書体・アイコンは自作する。
- 市販品・他社の名前は、コード・画面・登録情報・この仕様に書かない。調べたメモは公開リポジトリの外（Obsidian）に置く。
- 新ゲームの名前は、公開前にWeb検索で同名を調べる。重なれば改名する。
