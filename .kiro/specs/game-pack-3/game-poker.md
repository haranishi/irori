# ゲーム設計：持ち点ポーカー（poker）

要件 8（本人が2026-11-06に「持ち点だけで入れる」と選択）。2〜8人。1人でも CPU が席を埋める（推奨4人）。1局は10〜15分。遊びの規則（テキサス・ホールデム）は広く知られたもので、借りてよい。名前・絵・文・音・札の図柄は自作する。**お金・景品・課金は一切なし。持ち点はゲームの中だけで、外へ出せない。**

## 言葉と見た目（賭け事に見せない）
- ボタンの言葉：おりる／そのまま（チェック）／あわせる（コール）／ふやす（レイズ）／ぜんぶ（オールイン）。「ベット」「チップ」「賭ける」は使わない。点は「持ち点」、場に出た点は「たまり」と呼ぶ。
- 見た目は、カジノの緑の羅紗・サイコロ・硬貨の山を使わない。夕方の縁側のような、温かい木と紙の色。札の柄（♠♥♦♣）と数は、コードで描く自作の図形。

## 規則（広く知られた規則から、サイドポットをなくした形）
- 札：52枚。1人に手札2枚（本人のスマホだけ）。場の札は最大5枚（大画面に出す）。
- 1局＝6ハンド。全員の持ち点は1000から。ブラインド（強制の持ち点）：小10・大20（全ハンド同じ）。席の親（ボタン）は、ハンドごとに次の席へ。
- 1ハンド：配札 → 最初の行動（ブラインドの次の席から）→ 3枚公開（フロップ）→ 1枚（ターン）→ 1枚（リバー）→ 勝負。各段階で、残った全員が同額になるまで行動する。1人を残して全員がおりたら、その人が「たまり」を取る。
- 行動：おりる／そのまま（出す額が無いとき）／あわせる／ふやす（下の3種）／ぜんぶ。ふやす幅は、①大×2 ②たまりの半分 ③たまりと同じ。直前の増やし幅より小さい増額は選べない（押せない）。
- 出せる額の上限は、そのハンドに残っている人の持ち点の最小値（サイドポットを作らないため）。これを超える額は押せない。上限に達する行動は「ぜんぶ」と表示する。
- 勝負：残った人が、7枚から作る最強の5枚（役）を比べる。役の強さは広く知られた順（ロイヤルフラッシュ〜ハイカード）。同じ強さは、数の高さ→キッカー。完全な同点は「たまり」を等分し、端数は親の次の席から1点ずつ。
- 持ち点が0になった人は、その局のあいだ、次のハンドから見るだけ（席は残る）。1人を除いて全員が0になったら終了。
- 終了：6ハンドが終わったとき、または1人だけが残ったとき。順位は持ち点の高い順で、同点は同順位。得点（`score`）は持ち点。

## 時間と席の出入り
- 1回の行動は25秒。時間切れは、そのまま（出さなくてよいとき）かおりる。接続切れの席も時間で進む。席が退出したら、その席は自動でおりる（局は続く。人が1人も残らなければ勝負なしで1回だけ終える）。一時停止中は時間を止める。

## スマホの画面（`wait` と `tiles` だけ）
- 自分の番：`tiles`（行動の札。ラベル12文字以内：おりる・そのまま・あわせる 40・ふやす +40 …）。`note` に、手札（「あなた：♠A ♥K」）と、場の札・たまり・自分の持ち点の要約（120文字以内）。
- 番でないとき：`tiles` の見るだけ（`disabled`）と同じ `note`。勝負のあとは、自分の役の名前を数秒。
- 他人の手札は、勝負（残りが2人以上）まで、どの画面にも出さない。

## 大画面
縁側の卓に席の輪。名札・持ち点・「おりた」の印・番の光・親の印。中央に場の札（最大5枚）と「たまり」。勝負で、残った人の手札を表にして、役の名前と、勝った人を光らせる。下に直近4件の出来事。効果音は `deal` `flip` `place` `win` `lose`。動きを減らす設定を守る。

## CPU（cpu-seats.md の型。m=2→1・r=4）
- 手札の強さ：開始時の手札を段階で見る（強い組・中・弱）。公開後は、いまの役と、足りない札の数（フラッシュ・ストレートの狙い）で見る。見られる情報（自分の手札・場の札・公開の行動）だけで決める。
- 方針は「ふつう」：強い手は、ふやす・あわせる。弱い手は、そのまま・おりる。たまにだけ（種つき乱数で5〜10%）強気に出す。毎回同じ行動にならない。持ち点の保存（全員の合計が一定）を試験で守る。

## UXの5層（要約）
戦略＝集まった友達と、気楽な駆け引きを10分で終える／要件＝手札は本人だけ・番が分かる・何を出すと何が起きるか分かる・賭け事に見えない／構造＝配札→行動の周→公開→勝負→次のハンド→結果／骨格＝大画面は卓と場の札、スマホは上に手札・中央に行動の札／表層＝夕方の縁側の温かい色。

- 行動の合法性（押せない額・上限・増やし幅）、番外・古い `t` の拒否、時間切れ、退出。
- 秘匿：`publicView` と全員宛ての出力に、手札が勝負（残りが2人以上）まで出ない。
