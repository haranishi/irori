# ホーム画面：箱が並び、動画が流れ、選ぶと名前が出る

要件 7。2026-11-06 の本人の依頼（音声入力）。家庭用ゲーム機のホーム画面のように、箱が並んで選べる形にしたい。各ゲームの箱に、そのゲームの動画が流れる。箱にタイトルは出さず、選んだときに出す。タイトルは分かりやすく。QRは下に小さく出し、タップで大きくする。そのまま写すのは良くないので、色や形は変える。

## ユーザーストーリー
- ホストとして、箱の動画を見て「これを遊ぼう」と、説明を読まずに決めたい。
- 友だちとして、ソファから十字キーでもタップでも、同じように選びたい。
- 遅れて来た人として、下のQRをすぐ見つけ、遠くからでも読める大きさにしたい。
- 制作者として、ゲームを足したとき、動画を1本置くだけで箱が動くようにしたい。

## UXの5層
| 層 | 決めたこと |
|---|---|
| 戦略 | 「入って15秒で遊べる」（`docs/ux.md`）を保ち、ゲームを選ぶ時間を「見て分かる」ことで縮める |
| 要件 | 全ゲームが一目で見える／選ぶと名前と人数が出る／QRは常に下にあり、大きくもできる／十字キー・ゲームパッド・スマホのリモコン・マウス・タップで同じ操作 |
| 構造 | ホーム（箱の格子）→ 選ぶ（名前の帯）→ 決定 → ゲーム。QRの拡大は、どこからでも開いて戻れる重ね画面 |
| 骨格 | 上に細い帯（名前・参加者・音・共有）。中央に箱の格子（列数は幅で変わる）。左下にQRのカード。1280×720で収まる |
| 表層 | 囲炉裏の暗色の地に残り火の橙（既存の識別を保つ）。箱は角丸の動画。選んだ箱は少し大きくなり、暖色の光をまとう |

## 画面の決まり
- 箱：3:2・角丸28px・箱の間は24px。背景に敷く板は置かず、暗い地に箱が浮く。動画（`<video muted loop playsinline autoplay>`）が流れる。動画が無いゲームは、サムネイルの静止画。**箱に文字は出さない**。人数が足りない箱は、全体を暗くし、隅に人の印と必要な人数だけを出す。人数が多すぎる箱（参加者が最大人数を超える）も同じ作りで、人の印と最大人数を出す（理由は選んだときに名前の帯へ出す）。
- 格子：列数は幅で変える（600px 未満で2・900px 未満で3・900px 以上で4・1200px 以上で5・1700px 以上で6）。1ページは「列数×3行」の枠で、ゲームがそれより多いときは次のページ（左右の矢印とページの点）。余る枠は薄い破線の枠だけを出し、操作は無し。画面の大きさが変わっても、選んでいる箱を保ってページを組み直す。
- 選んだ箱：1.06倍になり、暖色の光。名前の帯は、格子の下に独立して出る（箱の下から上がる動きはしない）。帯に、ジャンル（`kind`）・名前・ひとこと（`summary`）・人数・時間（登録があるときだけ）・足りない人数・決定の合図（「あそぶ」）を出す。
- 文字の大きさ：名前の帯の説明・人数・時間と、右下の操作の案内は 1280幅で16px・1920幅で24px（`clamp(16px,1.25vw,24px)`）。小さなQRカードの理由は14px。
- 「あそぶ」：押せないとき（人数が合わない・参加者が0人）は、薄い輪郭と薄い文字。押せるときは橙の塗り。
- 選択とフォーカス：QR・道具・ページ送りにフォーカスがあるあいだは、選択している箱を細い枠だけにし、フォーカスのある要素を最も強く見せる。ページ送りの矢印は、格子の外に余白を取って箱に重ねない。
- リーダーのスマホの案内：ホーム＝「ゲームを選んで、［決定］を押してください」／QRを拡大中＝「QRを閉じるには［戻る］を押してください」／結果の画面＝「「もう一度」か「ホームへ」を選んで、［決定］を押してください」。ほかの席は今のまま。
- 操作：十字キー・ゲームパッド・リーダーのスマホで、箱を移動する。決定で遊ぶ、戻るでページの先頭へ。マウスは、重ねると選び、クリックで決定。タッチは、1回目のタップで選んで名前を出し、同じ箱をもう一度タップして決定する。
- QRのカード：画面の左下に、小さく浮かぶカード。全幅の帯にはしない。QR（約96px）と部屋コードを載せる。QRのタップ・決定・Qキーで、重ね画面に大きなQR（500px以上）・コード・アドレス・注意文を出す。1280×720・1024×576・1920×1080 のすべてで、「戻る」まで画面の中に収める（横長で高さが足りないときは、左にQR・右に文字と「戻る」の2列。縦長の狭い画面は縦に積む）。戻る・外側のタップで閉じる。参加者のチップ（色と形）と、音・参加の締め切り・共有・ライセンスのアイコンは、画面の上の帯の右へ置く。右下には、操作の合図（決定＝あそぶ・戻る）だけを小さく出す。
- 初回の案内：最初の1人が入るまで、「①QRを読む ②参加する ③ゲームを選ぶ」の3手順を、番号つきで大きく（1280幅で18px・1920幅で27px）、左下のQRカードのすぐ上に出す。スマホが参加できないアドレス（ローカルのアドレス）で開いたときは「①左下のQRを開く ②参加する ③ゲームを選ぶ」にし、小さなQRカードにも「このアドレスでは、スマホは参加できません」を出す（理由と開き直す方法は拡大したQRの注意文）。案内の位置の言葉は、いまの配置（QRは左下・道具は右上）だけを指す。
- 動画：見えている箱が全部流れる。画面外・タブが非表示・動きを減らす設定・省データのときは止めて静止画にする。1本は640×360以下・1MB以下・無音。同時に流すのは最大12本。置き場は `registry/previews/<id>.mp4`（作り方は [preview-videos.md](preview-videos.md)）。
- 写さないもの：参考にした画面の、4×3の固定配置・同じ枠の比率と余白・銀の枠や青い縁取り・背景の模様・全幅の下の帯（左右の端のボタンと中央の時計）・指差しの手形カーソルとプレイヤー番号の組・選択／起動／ページ送りの動きの順序と時間・起動音と選択音・書体・名称・ロゴ・既存のアイコン。選択の効果は、光と拡大だけにする。参考にした画面の名前を、製品名や宣伝の中心に置かない。

## 登録情報の追加（互換あり）
- `kind`：ジャンル名（ja・en、各12文字以内）。必須にはせず、無いときは出さない。
- `preview`：動画のファイル名。省略可。ビルドが `registry/previews/<id>.mp4` を見つけたら自動で入れる。旧ホストは無視する。
- `minutes`：遊ぶ時間の目安（分）。`{min,max}` の整数（1〜120、max は min 以上）。省略可で、無いときは帯に時間を出さない。実行時の読み取りと書き出しの両方で、範囲外・逆転を拒む。
- `kind` の初期値：hello-pad=お試し、tap-race=連打、dot-grab=点あつめ、quiz-4=クイズ、ten-seconds=タイミング、blade-duel=チャンバラ、lantern-market=数字カード、strike-alley=ボウリング、daifugo=トランプ、old-maid=トランプ、moon-village=人狼。新作は bell-in-sleeve=推理カード、poker=トランプ。

## 試験
- 1280×720・1920×1080・1024×576で、箱・QRのカード・名前の帯が欠けない。列数が幅で変わる。箱に見える文字が無い。
- 選ぶと名前の帯が出る（キーボード・タップ・マウス）。1回目のタップでは決定せず、2回目で決定する。
- QRのタップで拡大し、戻るで閉じる。拡大したQRをデコードして、部屋のURLと一致する。
- 動きを減らす設定で動画が止まる。画面外の箱が止まる。外部ドメインの読み込みが無い。axe の違反が0。
- 箱は、見えない名前（`aria-label`）に「名前、人数」を持つ。
