# 要件：第3弾

## 1. 権利の確認
1.1 新ゲームの名称・札の名前・文・絵は自作で、市販品の名称・文面・図柄・世界観を含まない。
1.2 札の構成（種類数・枚数・勝ち方・得点・罰）は、市販品と1対1に対応しない。
1.3 ゲーム名（日英）は、公開前にWeb検索で同名の既存ゲームを調べる。重なるときは改名する。結果は表で残す。
1.4 外部の画像・音・書体・コードを足さない。`npm run check` が通る。
1.5 確認済みと未確認（商標のJ-PlatPat・弁護士）を `docs/legal/` の表に残す。「調べていない」を「問題なし」と書かない。

## 2. ゲーム「ふところの鈴」（`bell-in-sleeve`）
2.1 3〜8人で遊べる。1局は6〜10分を目安にして、必ず終わる。
2.2 配札のとき、金の鈴の札は1枚だけ配られ、全員が同じ枚数を受け取る。人数ごとの構成は [game-bell-in-sleeve.md](game-bell-in-sleeve.md) の表による。
2.3 手札と、のぞいた結果は、本人のスマホだけに送る。大画面・全員宛て・公開の状態に載せない。
2.4 番の人だけが札を出せる。番でない席・古い画面の入力・押せない札・範囲外の選択は、状態を変えずに断る。
2.5 札を出すと、種類が全員に公開される。効果は5種類（のぞき見・すりかえ・ひそひそ話・つかまえる・かばう）で、解決は設計書のとおり。
2.6 「つかまえる」が鈴の持ち主に当たったとき、その局は屋台側の勝ちで終わる。外れたとき、指名した人は1点引かれ、指名された人がいま鈴を持っていないことが全員に知られる。
2.7 全員が決まった枚数を出し終えたとき、言い合い（制限時間つき）のあと、全員が同時に1人を指名する。最多票が鈴の持ち主なら屋台側の勝ち。同数なら逃げ切りで、鈴の持ち主の勝ち。
2.8 得点は設計書の表のとおりに付け、結果の画面で全員に見せる。同点は同順位。
2.9 席が接続切れのとき、制限時間のあとで合法な手を自動で選ぶ。席が退出したとき、その局は勝負なしで1回だけ終える。
2.10 一時停止のとき、制限時間を止める。再開で続ける。
2.11 同じ種（seed）と同じ入力の列から、同じ結果になる。

## 3. 画面と操作
3.1 スマホは `wait` と `tiles` だけを使い、文字は上限（札の文字12・補足12・注意120・ヒント40）に収める。
3.2 説明は1画面で足りる長さにする。番の流れ（札を選ぶ→相手を選ぶ→位置を選ぶ）は、1画面に1つの選択だけ出す。
3.3 番でない人のスマホには、自分の手札を見るだけの `tiles` と、いま誰が何をしているかの一行を出す。
3.4 大画面は、席の輪・各席の手札の枚数（伏せた札）・守りの印・出された札の山・直近の出来事を出す。鈴の位置は、結果の瞬間まで出さない。
3.5 動きを減らす設定のとき、移動の動きを切り替えの表示にする。
3.6 スマホ390px幅で札が欠けず、大画面1280×720で8人分が収まる。
3.7 効果音は固定の名前の一覧からだけ頼む。

## 4. 検証
4.1 判定は純粋な関数に切り出し、単体試験で守る（配札・各効果・番の進行・指名の集計・得点・拒否・秘匿）。
4.2 人数3〜8の無作為な対戦を各2000回行い、必ず終わる。簡単な方針の自動対戦で、屋台側と鈴の側の勝率を記録する。
4.3 実ブラウザ（Chromium・WebKit）で、実ホスト＋仮想スマホ3〜8台の通しを確かめる。他席のスマホに手札が届かない。
4.4 実際に遊ぶ別担当が採点する（20点満点・16点以上で0点の項目なし）。改善は3周まで。
4.5 実機・人どうしの遊び・商標特許は、未確認として残す。

## 5. CPUの席（[cpu-seats.md](cpu-seats.md)）
5.1 人の数が、そのゲームの最小人数より少ないとき、合計が推奨人数になるまで CPU が席を埋める。人が足りているときは足さない。
5.2 CPU は、人の席が見られる情報だけで手を選ぶ。隠れた情報を読まない。
5.3 CPU は、必ず合法手を選ぶ。考える時間は0.8〜2.0秒で、同じ種と同じ入力から同じ結果になる。
5.4 CPU の席は、ゲームの画面で人の席と区別でき、結果の画面に載る。コンソールの名簿と `end` には載せない。
5.5 1人＋CPU の局が、開始から結果まで必ず終わる。

## 6. イメージ動画（[preview-videos.md](preview-videos.md)）
6.1 全11本に、8〜12秒・無音・640×360・1MB以下の動画を作る。先頭から動き、ループが自然につながる。
6.2 撮影元はゲーム自身の画面だけで、外部素材・音・生成AIの映像を使わない。
6.3 道具が、大きさ・長さ・音声が無いこと・先頭が動いていることを検査する。

## 7. ホーム画面（[home-shelf.md](home-shelf.md)）
7.1 箱の格子（列数は幅で変わる）に全ゲームが並び、箱ごとに動画が流れる。箱に文字は出さない。
7.2 選ぶ（十字キー・マウス・1回目のタップ）と、名前・ジャンル・人数の帯が出る。決定で遊ぶ。
7.3 QRは左下の小さなカードに出し、タップで大きく表示する。戻るで閉じる。
7.4 動きを減らす設定・画面外・省データでは、動画を止めて静止画にする。
7.5 登録情報に `kind` と `preview` を足す（互換あり）。各ゲームの `kind` を入れる。
7.6 参考にした画面の意匠（4×3の固定配置・同じ比率と余白・銀の枠・全幅の下の帯・手形カーソル・動きの順序・音・書体・名称）を使わない（[docs/legal/game-borrowing-policy.md](../../../docs/legal/game-borrowing-policy.md) と home-shelf.md）。
