# ブリーフ：パーティーパック（第2弾）

## 依頼（2026-10-27・音声入力）
- irori の質を上げたい。目指す姿は、家庭用ゲーム機のスポーツゲームやパーティーゲームのように、みんなで対戦して遊べるゲームが何本もある形。
- いまのゲーム数と、どれだけ遊べるかを知りたい。
- ボウリング、みんなで遊べるカードゲーム、人狼を入れたい。著作権に気をつけて、できるか。
- 続けての指示：スキルとハーネスを使って実行する。参考にしてよい資料は、本人がGitHubでスターを付けたリポジトリ。

## 現状の棚（2026-10-27・コードと各READMEの実測）
| ゲーム | 人数 | 1回の長さ |
|---|---|---|
| hello-pad（見本） | 1〜8 | 30秒 |
| tap-race | 2〜8 | 約30秒 |
| dot-grab | 1〜8 | 45秒 |
| quiz-4 | 1〜8 | 約3分（8問×15秒） |
| ten-seconds | 2〜8 | 約3分 |
| blade-duel | 2 | 3〜5分（最大10手） |
| lantern-market | 2〜8 | 4〜6分（6市） |

全部を1回ずつ遊んでも約20分。1回が30秒〜6分の短いゲームが中心で、8人が10分以上盛り上がる定番（運動・札・会話）がない。

## 問題
- 長く遊べる定番がない。ボウリング・札遊び・人狼は、どれも家族や友人の集まりで最も使われる型。
- コントローラーの「選択」は2〜6個・12文字まで。手札（最大18枚）の複数選択と、最大8人の投票が出せない。
- 音がない。コンソールの消音の設定がゲームに伝わらないため、同梱ゲームは無音にしてある（`docs/known-issues.md`）。

## 方針
- 4本を足して11本にする：ストライク横丁（ボウリング）、大富豪、ババ抜き、月あかりの寄り合い（人狼）。
- コントローラーは `tiles`（札や人を並べて選び、決定する）を1種類だけ足す。能力の申告（`pad-tiles-v1`）で守り、旧ホストと既存7本は変えない。
- 音は、ゲームが決まった名前の効果音を頼み、コンソールが自前の合成音（ファイルなし）で鳴らす仕組み（`cue-v1`）を足す。消音はコンソール1か所で効く。間に合わなければ無音のまま出す。
- 判定は純粋な関数に切り出し、試験で守る。画面と手触りは、実ブラウザで撮って直す。

## 範囲外
オンライン対戦、CPUの参加者、賭け・課金、ポーカーなど金銭に近い札遊び、既存7本の改修、公開デモの再デプロイ（本人の判断）、傾きセンサーでの投球（実機の検証が先）。

## 制約
- 他社の名称・商品を、コード・画面・登録情報・この仕様の文書に入れない。禁止語は `tools/check-rights.mjs` が持つ。札遊びや人狼の市販品の名前も同じ扱い。
- 見た目・音・文は独自に作る。ゲームの規則（アイデア）は借りてよいが、他社の絵・文・音・コードは写さない。
- 新しい依存と、音声・書体のファイルを足さない。文書は1ファイル100行以内。私的な絶対パスを、どのファイルにも書かない。
- 追加のpushと本番反映は、本人に確認してから行う。
