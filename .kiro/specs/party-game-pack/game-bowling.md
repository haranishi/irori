# ゲーム設計：ストライク横丁（strike-alley）

要件 7.1〜7.6。1〜6人が交代でボールを投げ、10フレーム（短いモードは5フレーム）の合計点を競う。判定と物理は純粋関数にし、画面は再生するだけにする。

## 1投の操作（スマホは `touch` の swipe 1画面）
指をおく横位置が、ボールを置く位置。下へ引いた長さが強さ。引いたまま左右にずれた量が曲がり（フック）。はなすと投げる。
- 入力は `ptr` の s（開始）・m（移動）・e（終了）。時間は使わず位置だけで決める。回線の遅れが結果に響かない。
- `readThrow(samples)`：s と e がそろい、引き（y_e − y_s）が0.12以上のときだけ投球にする。それ以外は「投げない」を返し、もう一度引ける。
  - startX：0〜1を−0.85〜+0.85に写す（レーンの半幅が1）。power：(引き−0.12)/0.63 を0〜1に切る。球速は5.0〜9.0 m/s。
  - hook：(x_e − x_s)/0.35 を−1〜1に切る。±0.04は0にする。ヒント文は「指をおいて、下に引いて、はなす」。
- `previewThrow(samples)`：途中の指から同じ形を返す。大画面の狙い線・強さの目盛り・曲がりの予想線に使う。更新は毎秒20回以下。

## 物理（`physics.js`・決定的）
単位はメートルと秒。レーン幅1.05、ファウルラインz=0、ヘッドピンz=18.29、ピン間隔0.305。ピン10本は三角形（1番がヘッド、2〜3、4〜6、7〜10）。
- 固定刻み1/240秒。球は半径0.109・質量6.35、ピンは当たり半径0.05・質量1.5。球速の上限は10 m/s（刻みあたりの移動を当たり半径より小さく保ち、すり抜けを防ぐ）。
- 曲がりは横向きの加速で表す。前半（z<4）は油で滑って曲がらず、後半（z>12）で強く曲がる。`ax = hook × H × ramp(z)`。
- 球の中心が縁（|x|>0.51）を越えるとガター。以後は横に動かず、ピンに当たらない。
- 当たりは円どうしの反発（係数0.5）。衝撃が閾値以上のピンは倒れ始め、倒れたピンは大きな円（半径0.09）として滑り、他のピンを倒す。弱い衝撃では立ったまま。
- 倒れた判定：衝撃が閾値以上、倒れたピンに当てられた、またはデッキの外へ出た。一度倒れたピンは立たない。
- 出力：`{ down:boolean[10], knocked, gutter, durationMs, frames }`。`frames` は60Hzの位置と傾きの再生データ。乱数を使わず、同じ入力は同じ出力になる。
- 調整の目標（調整表を試験で固定する）：startX −0.8〜0.8を0.04刻み、hook −0.8〜0.8を0.2刻み、power 0.7の全組で、ストライクは全体の5〜30%。ある hook で startX が4刻み（0.12）以上連続してストライクになる。縁へ向かう曲がりでは0本。

## 得点（`scoring.js`・純粋）
- ストライクは10＋次の2投、スペアは10＋次の1投、それ以外は倒した本数。最終フレームは、ストライクかスペアなら最大3投。10フレームの満点は300、5フレームの満点は150。
- `scoreCard(rolls, frames)` は各フレームの表示（X・/・−）、累計（確定前はnull）、合計、終了を返す。`nextTurn(rolls, frames)` は次の投球の位置と、ピンを立て直すかを返す。
- 試験：満点、全ガター0、全スペア（毎回5）150、途中のフレーム、最終フレームの全パターン、短いモードの境界。

## 進行（`logic.js`）
形は既存と同じ `createGame` / `updateGame` / `publicView`。段階は intro（モード選択）→ aim → rolling → settled → ended。
- intro：リーダーに `choices`（ふつう10フレーム／みじかめ5フレーム）。決めたら開始。それ以外の席は `wait`。
- aim：番の席だけに `touch`。ほかは `wait`（誰の番か、何フレーム目か、自分の合計）。最初の入力は s。s のない m・e は無視。ほかの席の入力、番の外の入力も無視する。
- 投げたら `physics` を1回だけ走らせる。大画面は `frames` を時間で補間して再生し、終わると `settled` を送る。再生の速さで結果は変わらない。
- settled：倒した本数を記録し、字幕（ストライク／スペア／ガター／N本）を出す。1投目でピンが残れば同じ席がもう一度。それ以外は次の席。
- 席が消えたら、その席の残りを飛ばして続ける（結果に「退出」・順位なし）。2人以上で始めて、順位を付けられる席が1人になったら、全員の記録を残して順位なし（未成立）で終える。1人で始めた勝負は、そのまま続ける。接続切れの席の番は、戻るまで待つ。
- 一時停止：再生と時計を止め、指の途中経過を捨てる。再開後に同じ場面から続ける。
- 結果：合計の多い順。同点は同順位。`display: 'points'`。

## 大画面と手触り
- 手前から奥へ見る遠近のレーン。ボールが進むとカメラがゆっくり寄り、衝突で引く。得点表は10フレームの標準の形（X・/）で、番の席を強調する。
- 衝突の重ね方：玉の転がり（回転する模様と軌跡）→ ピンの舞い（回転しながら倒れる）→ 粉の火花 → 字幕のポップ（行き過ぎてから戻る）。ストライクだけ、約90msの静止・揺れ（減衰）・灯りの脈動を加える。ガターは玉がしょんぼり揺れる。
- 効果音の依頼：転がり `roll`、衝突 `pins`（強さ=倒した本数/10）、`strike`、`spare`、`gutter`。投げた人のスマホにだけ短い振動（ストライクは長め）。
- 動きを減らす設定では、揺れ・静止・舞いをやめ、字幕と得点の変化だけにする。

## 試験（要件 7・5・6）
- 純粋層：上の調整の目標、満点・ガター・全パターンの得点、ピン数が0〜10で倒れたものが立たないこと、同じ入力で同じ出力、拒否される入力（古い・他席・投げない）、退出と一時停止。
- 実ブラウザ：実ホスト＋スマホ2〜3台で、引いてはなす→再生→字幕→次の席→結果。CPUを4倍遅くしても同じ本数。Chromium と WebKit。
