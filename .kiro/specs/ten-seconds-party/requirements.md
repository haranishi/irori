# 要件：せーので10秒

## Introduction
飲み会や友人の集まりで、説明や準備に時間を使わず、同じ画面を見て笑える短いゲームを作る。
共用の画面で一斉に数え始め、10秒だと思った瞬間に各自のスマホで一度押す。結果を一斉に発表し、3回の合計のズレを競う。
2026-10-18、本人がこの要件案を承認した。人数・回数・採点・中断処理は以下を正本とする。

## Boundary Context
- 含む：2〜8人、10秒固定・3ラウンド、結果の一斉発表、再戦、中断と復帰、既存の参加・共有への接続。
- 含まない：部屋や認証の新設、スマホだけを回すモード、個別の目標秒数、オンライン競技の精度保証、永続ランキング、公開作業。
- 隣接する約束：iroriのQR参加、席の識別、リーダー、60秒の再接続猶予、結果・共有を引き継ぐ。途中参加は次の一勝負から。
- 初版の計測は大画面の開始合図からゲームが入力を受け付けるまで。通信の遅れを含み、0.1秒表示は精度の保証ではない。
- 用語：一勝負＝3ラウンド。試行＝中断によるやり直しも区別した1回の計測。リーダー＝iroriが指定する進行役。

## Requirements

### Requirement 1: 参加して遊び方が分かる
**Objective:** 集まった人として、各自のスマホですぐ参加し、説明を読み込まず遊び始めたい。
1. When 2〜8人が参加して本ゲームを開いたとき, the Game shall 共用画面に参加者と「10秒だと思ったら1回押す。3回の合計のズレで勝負」を表示する。
2. If 参加者が2人未満のとき, the Game shall 開始を受け付けず、必要な人数を表示する。
3. When リーダーが説明画面で「はじめる」を選んだとき, the Game shall 第1ラウンドの開始予告へ進む。
4. When 一勝負の途中で新しい人が参加したとき, the Game shall 次の一勝負から参加できる待機状態を示す。
5. If 参加席に切断中の人がいるとき, the Game shall 開始予告へ進まず、再接続または退出を待つ。

### Requirement 2: 全員が同じ合図で数える
**Objective:** プレイヤーとして、他人の操作を手掛かりにせず、自分の10秒の感覚で勝負したい。
1. When 各ラウンドの開始予告に入ったとき, the Game shall 停止操作を案内した後、共用画面に「3・2・1・せーの」を1秒間隔で表示する。
2. When 「せーの」を表示したとき, the Game shall 全員に共通する計測を開始する。
3. While 計測中である間, the Game shall 周期的な音や点滅を使わず、経過秒数と押した人・人数・時刻を表示しない。
4. When 開始から20秒未満にプレイヤーのその試行で最初の停止操作を受け付けたとき, the Game shall その人の記録を確定し、本人にだけ「受け付けました。大画面を見てね」を表示する。
5. If 開始前、回答済み、中断中、受付終了後、または過去の試行に対応する停止操作が届いたとき, the Game shall 記録と順位を変更しない。
6. When 全員の記録が確定したか、開始から20秒に達したとき, the Game shall 入力受付を終了して結果発表へ進む。
7. When 20秒の受付終了時に未回答者がいたとき, the Game shall その人を「時間切れ」と記録する。

### Requirement 3: 結果と順位に納得できる
**Objective:** プレイヤーとして、誰がどのくらい早かったか・遅かったかを一緒に見て楽しみたい。
1. When 結果発表に入ったとき, the Game shall 全員の記録秒数と10秒との差を同時に公開し、時間切れは実測秒数を付けず「時間切れ・採点用のズレ10.0秒」と表示する。
2. The Game shall 記録秒数を0.1秒単位に四捨五入し、その値から10.0秒との差を計算する。
3. When 3ラウンドが完了したとき, the Game shall 各ラウンドの差の絶対値を合計し、3ラウンドを終えた残存参加者を、小さい順に順位付けする。
4. If ラウンドが時間切れだったとき, the Game shall そのラウンドの合計用のズレを10.0秒とする。
5. If 合計のズレが等しい人がいたとき, the Game shall 同順位・同率優勝を表示し、受付順で順位を分けない。
6. The Game shall 説明と結果に「通信の遅れを含む目安です」を表示し、競技用の精度を約束しない。
7. When 参加者が一勝負の途中で退出したとき, the Game shall 確定済みの記録を「退出」として残し、順位なしで掲載し、最終優勝の対象から外す。

### Requirement 4: 飲食や会話の間に短く遊べる
**Objective:** 進行役として、操作の説明を繰り返さず、結果を見て次の勝負へ進めたい。
1. When 第1・第2ラウンドの結果を表示したとき, the Game shall ラウンドの順位と累計を表示し、リーダーに「次へ」を提示する。
2. When リーダーが「次へ」を選んだとき, the Game shall 次ラウンドの開始予告へ進む。
3. When 一勝負が完了したとき, the Game shall 合計のズレ、順位、「もう一度」「ホームへ」と既存の共有への入口を提示する。
4. When リーダーが「もう一度」を選んだとき, the Game shall 現在の参加者で新しい一勝負を始め、前の記録を採点に混ぜない。
5. The Game shall 正常に3回を計測し、結果を各5秒見て進めた場合、説明後の開始操作から最終結果まで100秒以内で到達できるようにする。

### Requirement 5: 中断で不利な得点を付けない
**Objective:** プレイヤーとして、回線切れや一時停止で勝負を失わず、何を待っているか分かりたい。
1. When 開始予告または計測中に一時停止・共用画面の非表示・参加者の切断・退出・除外を検知したとき, the Game shall 当該試行を全員分無効にし、確定済みの過去ラウンドの記録を保持する。
2. While 切断した席が再接続の猶予内にある間, the Game shall 同じ席と過去ラウンドの記録を保持し、「つなぎ直しを待っています」を表示する。
3. When 中断理由が解消したとき, the Game shall リーダーの再開操作を待ち、同じラウンドを開始予告からやり直す。
4. When 再接続の猶予切れ・退出・進行役による除外で席が消えたとき, the Game shall その人を退出扱いにし、残る2人以上で再開できるようにする。
5. If 一勝負の途中で参加者が2人未満になったとき, the Game shall 全員を順位なし・勝敗未成立として終了し、理由と再戦・ホームへの入口を表示する。
6. When 結果発表中に切断が起きたとき, the Game shall 発表済みの記録を保持し、次の開始前に再接続を待つ。
7. When 共用画面の通信切断を検知したとき, the Game shall 進行を止め、開始予告・計測中だった試行を無効にし、復帰後は再開操作を待つ。
8. When 共用画面を再読み込みしたとき, the Game shall 過去の一勝負を再開せず、既存のホームへ戻る。

### Requirement 6: 片手と大画面で迷わず操作できる
**Objective:** プレイヤーとして、会話しながら片手で押し、自分の記録を離れた画面から読めるようにしたい。
1. The Game shall 停止操作をスマホ縦画面の1ボタンにまとめ、指で押せる領域を最低48×48 CSSピクセル確保する。
2. The Game shall 開始合図、記録、順位を文字で示し、音や振動がなくても一勝負を完了できるようにする。
3. The Game shall 参加者を名前・色・形で識別し、色だけで記録を区別しない。
4. The Game shall 1280×720の共用画面と390×844のスマホ画面で、8人の結果と主要操作が重ならず読めるようにする。
5. When 動きを減らす設定が有効なとき, the Game shall 点滅や拡大演出を使わず、同じ情報を表示する。

### Requirement 7: 既存の参加・共有・データの扱いを守る
**Objective:** 参加者として、新しい登録や権限の許可をせず、一緒に遊びたい。
1. The Game shall 既存の参加用ニックネームと席情報だけで遊べるようにし、新しいアカウントやカメラ・マイク・位置情報を要求しない。
2. The Game shall 得点を一勝負の間だけ保持し、永続ランキング・解析・広告・課金への接続を追加しない。
3. When 結果を共有するとき, the Game shall 他の参加者の名前や記録を共有文に含めず、ゲームへの案内を共有する。
4. The Game shall 操作・参加・再接続の説明に、内部の通信方式や開発者向けの用語を表示しない。
