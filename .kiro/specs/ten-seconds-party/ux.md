# 体験と画面：せーので10秒

要件承認済みの内容を実装した。独立した[実操作評価](../../../.agent-harness/runs/2026-10-18-ten-seconds/experience.md)は19/20、[画面評価](../../../.agent-harness/runs/2026-10-18-ten-seconds/ui-review.md)は18/20で合格。物理端末と人間同士の面白さは未確認。

## 遊びの核
「10秒だと思ったら、1回押してね。結果はみんなで見るよ」
押し終わった人は画面を見上げ、全員の早い・遅いの違いを一斉に見る。
計測中の視線は共用画面へ、操作は手元の1ボタンへ分ける。

## ユーザーストーリー
| 人・場面 | したいこと | 受け入れ条件 |
|---|---|---|
| 最初に開く人 | その場の人を誘いたい | 既存QRで参加者を見られる |
| 初めて遊ぶ人 | すぐ遊びたい | 1文の説明、文字の開始合図、1回の停止で遊べる |
| 飲食中の人 | 片手で押したい | 縦画面で大きい1ボタン。持ち替え・追加入力なし |
| 押し終わった人 | 答えを一緒に見たい | 本人にも秒数を先出しせず、全員の結果を一斉公開 |
| 進行役 | 会話の区切りで次へ進みたい | 結果を自動で消さず、「次へ」で進む |
| 遅れて来た人 | 次の勝負に入りたい | 待機理由が見え、再戦から参加できる |

## UX5階層
| 階層 | 決めたこと |
|---|---|
| 戦略 | 飲み会や友人の集まりに1〜2分の共通の話題を作る |
| 要件 | 2〜8人、10秒固定3回、同順位、結果秘匿、中断は同じ回だけやり直す |
| 構造 | 説明→予告→計測→発表。3回目の発表から総合結果へ進み、既存の再戦・共有を使う |
| 骨格 | 共用画面は合図と記録、スマホは停止と自分の席。回答人数を計測中に出さない |
| 表層 | iroriの暖色を継承。計測中は音・点滅・動きのない静かな画面。記録は0.1秒単位の文字 |

## 画面と操作
| 場面 | 共用画面 | 各自のスマホ |
|---|---|---|
| 説明 | 1文のルール、参加者、遅延の注記 | リーダーは「はじめる」、ほかは待機 |
| 開始予告 | 第1回 / 3、3→2→1 | 停止の案内。「せーの」が出るまで押さない |
| 計測 | 「せーの」を出してから静止。秒数・回答状況なし | 「10秒！」の1ボタン、hintで押す意味を案内 |
| 自分が停止 | 共用画面の見た目は変えない | 「受け付けました。大画面を見てね」 |
| 第1・第2回の発表 | 全員の秒数、早い／遅い差、今回の順位、累計 | リーダーは「次へ」、ほかは大画面を見る案内 |
| 第3回の発表 | 同じ項目を一斉表示し、3回目の記録も確認できる | リーダーは「総合結果へ」 |
| 総合結果 | 合計のズレ、同順位、退出、注記、再戦・ホーム・共有 | 既存の結果リモコンへ戻る |
| 中断 | この回はやり直しと理由。過去の記録は保持 | 解消前は待機、全条件が戻るとリーダーに「やり直す」 |

人数不足で終えたときは「人数が足りないため、今回は勝敗なし」。記録は順位なしで残す。
結果中の切断は結果を表示したまま待ち、次へを再接続まで止める。
通常の1ラウンドは1回押すだけ。中断復帰や進行操作は、進行役が担当する。

## 骨格と文字
共用画面の基準は1280×720。上64pxに回数と見出し、中央に最大8行、下に注記と主操作を置く。
左右40px、8行は1行52pxを上限の目安とし、本文24px以上、主要な記録32px以上で試す。
列は席・名前・今回の秒数・早い/遅い差・累計。色と形も出し、名前だけで行を探させない。
総合結果では合計記録を主役にし、点数欄を隠す。人数が多いときも注記と再戦を画面内に収める。
スマホは390×844を基準に、既存の席表示とメニューを維持する。1ボタンpadの既存スタイルを使う。
停止領域は最低48×48px。追加の巨大buzzerや自由HTMLは導入せず、実機で押しやすさを確かめる。
キーボードのEnter/Spaceでも操作でき、フォーカスの輪を消さない。

## 表層
背景#1a1411、面#2f241d、文字#f5ebe0、補足#c9b8a6。プレイヤー色と形はSDKのlookを使う。
開始合図は96px以上を目安に、結果の変化は180ms以内。計測中は定期的なアニメーションを使わない。
reduced-motionでは拡大・点滅を使わず、同じ文字情報をそのまま出す。
OSの書体だけで動作させる。公開サムネイルは既存のOFLフォント生成手順を使う。
本ゲームから音・振動は送らない。開始と発表はaria-liveでも一度だけ知らせ、毎秒の計測値を読み上げない。
文字は4.5:1、大きい文字・輪郭は3:1以上を実装後に確認する。

## 表示の例
- 記録：「9.7秒」「0.3秒 早かった」
- 同率：「ふたりとも、ズレの合計0.4秒。同率1位！」
- 時間切れ：「時間切れ」「採点用のズレ10.0秒」。20.0秒の実測として表示しない
- 中断：「今回はやり直し。ここまでの記録はそのまま」
- 注記：「通信の遅れを含む目安です」
- 共有：「せーので10秒。みんなの10秒、どのくらい違う？」

## 設計から変えた判断
計測中の参加者ごとの光・完了マークは付けない。ほかの人が押した時刻を手掛かりにできるため。
結果はリーダー操作まで残す。会話の途中で自動的に次の回へ切り替えないため。
最後の回の秒数も一斉発表してから総合結果へ進む。合計だけで終わって第3回の違いが見えなくなるのを防ぐ。
