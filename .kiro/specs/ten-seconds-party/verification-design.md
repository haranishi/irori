## 実装後の実行順
型・単体→実Worker結合→実ブラウザE2E→登録/権利/文書/SDK同期→必要な変異試験→容量→体験とUIの評価。
既存コマンドは `npm run typecheck`、`npm test`、`npm run test:e2e`、`npm run check`、`npm run mutations`、`npm run budgets`。
重要な時計・入力・順位の守りは、外すと対応試験が赤くなるところまで確認する。
入力の間隔・遅れを0〜500ms、CPUの遅い条件でも振る。通信の遅れに関係なく同じ記録になるとは期待しない。
Safari系とChromiumで確認する。実機の遅れ、飲み会での面白さは本人のプレイで確かめ、未確認を合格扱いしない。
