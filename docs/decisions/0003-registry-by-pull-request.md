# ADR 0003：ゲームの登録はPRで、置くのは登録情報だけにする

状態：採用（2026-10-16）

## 背景

「誰でもゲームを足せる」を実現したい。保守者は1人で、返信できるのは週に1回ほどになりうる。

## 決めたこと

窓口は作らない。`registry/games/<id>.json` とサムネイルをPRで足してもらい、CIが形と動作を確かめ、保守者が権利と内容を読んで取り込む。ゲーム本体は、制作者が自分で配信するか、このリポジトリの `games/` に置く。

## 捨てた案

- **アップロードの窓口とアカウント**：保管、容量、審査、通報、個人情報、利用規約を、すべて運用することになる。1人では抱えられず、問題が起きたときの責任も重い。
- **URLを自動で集める**：品質と権利を誰も見ない棚になる。
- **登録を保守者だけに限る**：「誰でも足せる」ではなくなる。

## 代償と、見直す条件

制作者には、GitHubのアカウントとPRの手順が要る。入口を広げるために、コードに触れない作業（サムネイル、説明、翻訳）と、登録を頼むIssueのひな形を用意する。

PRが月に10件を超えて審査が滞ったら、審査を手伝える人を募る。権利や内容を判定する自動審査は、誤判定の責任を負えないので作らない。
