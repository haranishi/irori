# ADR 0006：体験の型は借り、見た目・音・言葉は独自のものにする

状態：採用（2026-10-16）

## 背景

着想は、スマホをコントローラーにして、ゲームの一覧から選んで遊ぶ既存のWebサイトと、家庭用ゲーム機のメニューの考え方から来ている。体験の型（QRで入る、一覧から選ぶ、スマホで操作する）は、誰が使ってもよいアイデアだ。一方で、画像・音・文章・配色・タイルの形・ロゴは、作った人の表現で、似せると権利の問題になりうる。

## 決めたこと

- 借りるのは、体験の型だけ。QRで入る、一覧から選ぶ、スマホが操作の道具になる、最大8人、という流れ。
- 借りないもの。背景のしま模様、ページ送りの格子（1ページに12個）、時計つきの下の帯、水色のアクセント、効果音、書体、文言、他社の名称とロゴ。角の丸い横長のカードを並べる形は、ありふれた構成なので、避けない（こちらは4:3で、主役の1枚と横の棚にした）。
- 見た目・音・言葉・画像は、自分で作る。音は合成し、画像はコードで描き、書体はOSのものを使う。
- 参考にしたサイトのコードと素材は取り込まない。観察した事実の記録だけを `docs/research/` に残す。

## 捨てた案

- **似せて、利用者が迷わないようにする**：見慣れた見た目は初見に有利だが、権利の確認に責任を負えない。迷いを減らすのは、色と形・大きさ・文言の工夫でできる。
- **許可を得る前提で似せる**：連絡先が分からず、返事を待てない。

## 代償と、見直す条件

見た目の洗練に時間がかかる。そのため [identity.md](../identity.md) に決まりを書き、`tools/check-rights.mjs` が禁止語と素材の種類（音声ファイル、書体ファイル）を機械で拒む。参考サイトの作者から連絡があれば、見直す。
