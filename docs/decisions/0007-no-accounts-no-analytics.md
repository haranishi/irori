# ADR 0007：アカウント、解析、広告、課金を持たない

状態：採用（2026-10-16）

## 背景

利用の中心は、友だちや家族が1つの画面を囲むこと。参加者には子どももいる。保守者は1人。

## 決めたこと

- ログインを作らない。席は部屋の中だけで有効で、部屋は最長12時間で消える。
- 解析、広告、課金、外部のフォント・画像・スクリプトの読み込みを入れない。コンソールは `Set-Cookie` を返さない。
- 名前は、参加者が打った短い文字だけ。サーバーに保存せず、部屋が消えれば消える。
- 運営者が独自に解析を足すのは自由だが、リポジトリの既定には入れない。

## 理由

アカウントと解析は、個人情報の保管、削除の依頼、外部送信の通知（電気通信事業法の外部送信規律）、子どもの扱いといった運用を連れてくる。保守者1人では責任を負えない。ランキングやフレンドも、アカウントがなければ作れないので、持たない。

## 代償と、見直す条件

利用の人数や継続率を測れない。測りたいときは、運営者が自分のデプロイで、同意と通知の手続きとあわせて足す。参加者が増え、アカウントがないことで困る声が複数出たら、別のサービスとして切り出す形を考える。この本体には入れない。
