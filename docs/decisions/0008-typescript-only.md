# ADR 0008：言語はTypeScriptだけにする

状態：採用（2026-10-16）

## 背景

ゲームを作る人の多くは、普段JavaScriptかTypeScriptを書く。保守者の別のOSSにはRust製のものもあるが、このプロジェクトの主役は、ブラウザとWorkerだ。

## 決めたこと

ブラウザ、Worker、ツール（Nodeのスクリプト）、試験のすべてをTypeScript（一部は設定のためのJSON）で書く。同梱のゲームは、ビルドなしで動く素のJavaScriptでもよい。

## 捨てた案

- **中継やSDKをRust（WASM）で書く**：速さが要る処理がなく、参加の入口を狭めるだけ。
- **点検の道具をPythonやシェルで書く**：言語が増え、読める人が減る。

## 代償と、見直す条件

型は実行時には消える。信用できない入力を受ける境界（中継、ホスト、ゲームとの橋渡し）では、必ず `packages/protocol` の検証を通す。この規則を破ると、型が通っても壊れる。
