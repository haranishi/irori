# 見た目と音は、囲炉裏の暖かさを軸に、すべて自分で作る

暖かい暗色の地に、残り火のような淡い光を置く。名前の由来は囲炉裏で、1つの火のまわりに人が集まる絵が基準になる。体験の型は借りても、見た目・音・言葉は借りない（理由は [ADR 0006](decisions/0006-original-identity.md)）。ここに書いた値は出発点で、画面で測ってから直してよい。ただし、下の測れる基準は守る。

## 色

| 役割 | 値 | 使いどころ |
|---|---|---|
| 地 `--bg` | `#1a1411` | 画面全体。平坦な暗色に、中央からごく弱い放射状の光を重ねる |
| 面 `--bg-card` | `#2f241d` | カード、パネル |
| 線 `--line` | `#4a382c` | 区切り、枠 |
| 文字 `--text` | `#f5ebe0` | 本文と見出し |
| 弱い文字 `--text-dim` | `#c9b8a6` | 補足 |
| 光 `--glow` | `#ffd9a0` | 選択中の輪、押せるものの強調 |
| 火 `--ember` | `#ff8a3d` | 装飾の光、進行の帯。文字の色には使わない |

プレイヤーの色は、色覚に配慮した8色（Okabe-Itoの7色に、地に沈まない薄灰）を使い、**必ず形と対にする**。色は `#E69F00` `#56B4E9` `#009E73` `#F0E442` `#0072B2` `#D55E00` `#CC79A7` `#EDEDED`、形は丸・四角・三角・ひし形・星・十字・六角形・輪の順。色と形は席番号で決まり、`irori.look(id)` で同じものが返る。UIの色（光・火）とプレイヤーの色は、使う場所を分ける。赤と緑で意味を分けない。

## 形と動き

- カードは横長の4:3、角丸は14px（角の丸い横長のカードを並べる形は、ありふれた構成）。ページ送りの格子（1ページに12個）や、しま模様・格子の背景は使わない。影は暖色のやわらかい光で、くっきりした黒い影は避ける。
- 選択中のカードは1.06倍に拡大し、光の色の輪を3px出す。動きは0.18秒以内。`prefers-reduced-motion` では拡大と流れる動きを止める。
- 画面の下に帯を常設しない。時計は出さない。QRとコードは右下の1か所にまとめる。

## 文字

OSの書体だけを使う（`ui-rounded` `Hiragino Maru Gothic ProN` `Yu Gothic UI` `Noto Sans JP` `system-ui`）。Webフォントは読み込まない。ただし、公開する画像（OGP画像・棚のサムネイル）の文字は、OSの書体で描かず、再配布してよい Noto Sans JP（SIL OFL 1.1）で描いた画像にする（`tools/lib/ofl-fonts.mjs`）。OSの書体で描いた画像を、CC BY 4.0 で配るのを避けるため。ホストの本文は1080pで24px以上、見出しは40px以上、部屋のコードは120px以上の等幅で、字の間を広くする。スマホの本文は16px以上、ボタンは48px四方以上。

## 音

音声ファイルは持たず、WebAudioで合成する。6つ（移動・決定・戻る・参加・開始・結果）で、どれも250ms以内、既定の音量は0.25。最初の操作のあとに有効になり、Mキーとメニューで消せる。木をたたく音や鈴のような、囲炉裏端の響きを基準にする。

## 測れる基準

- 文字のコントラストは4.5:1以上（大きい文字と部品の輪郭は3:1以上）。
- 外部ドメインから、画像・書体・スクリプトを読み込まない。
- リポジトリに、音声と書体のファイルを入れない。
- 画面の文言とソースに、禁止語を入れない（`tools/check-rights.mjs` が機械で拒む）。

## 借りないもの

次は、この見た目のルールが避けているもの。参考にした既存のサイトやゲーム機の、画像・音・文言・配色・タイルの形・ロゴ・書体、そして他社の商標。権利者の名称とロゴは、名前にも画面にも説明にも、比較のためであっても画面には出さない。文書の中での言及は、事実を述べる範囲にとどめる（[legal/reference-policy.md](legal/reference-policy.md)）。

## ロゴ

「irori」の字と、火を表す小さな形を、自分で描く。SVGで持ち、ファビコンとOGP画像（1200×630）もそこから作る。OGP画像は、ビルドで画面の描画から生成し、手で加工した素材を混ぜない。
