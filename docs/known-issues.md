# 既知の問題と限界：実際に遊んで見つけたものと、まだ確かめていないこと

2026-10-16 に、評価者（AI）が試遊サーバーで4本を計18回遊び、ホストの画面を採点した。その記録からまとめた。再現の手順は [scoring-experience.md](../.agent-harness/runs/2026-10-16-bootstrap/review/scoring-experience.md) にある。コンソールは19/20点で合格、ゲームは4本中2本が合格線（16点以上で、0点の項目がない）に届いた。「未修正」のものは、報告も修正も歓迎する。

## 遊んで見つけた問題

| 何が起きるか | 状態 |
|---|---|
| 8人のとき、開始の案内（メニューの開き方・音）が、4択クイズの6〜8人目の点の札と、連打レースの8人目の回数の札に、約10秒重なる | 未修正 |
| 8人の結果は、1280×720 だと「もう一度」「ホームへ」が画面の下で切れる | 未修正 |
| ゲームの途中で抜けた人が、連打レースの結果には「退出」で残る。ほかの3本では、結果から消える | 未修正 |
| 4択クイズで、8人が同じ長い答えを選ぶと、答え合わせの文字が枠からはみ出す。抜けた人の札は「退出」でなく「切断」と出る | 未修正 |
| あつめて点は、光の輪に触れても取れない。取れる距離（32px）が、描いている輪の縁（42px）より短い | 未修正 |
| ハローパッドは、時間制限も目標もなく、2回目に新しくすることがない。「まず試す」ための見本として作った | 未修正 |
| 連打レースで、始める前から切れていた人も走者に入る。切れた席が外れるか、30秒たつまで終わらないことがある | 仕様（切れても、席が消えるまで参加者のまま） |
| ホストの画面を読み込み直すと、遊んでいたゲームは結果なしで終わり、ホームに戻る。スマホに理由は出ない | 仕様 |
| 一時停止メニューの「ホームへ」は、確認なしでゲームを終える | 未対応 |

## 画面の採点で残った点

ホストの大画面は17/20点で合格した。残る減点は3つある。ホーム右の板で、見出しとQRの間が約160〜290px空く。2つの画面（部屋を作れない場合と、自分の端末のアドレスで開いた場合）で、文が不自然な所で折れる。ゲームの詳細の縮小画像の上下に、黒い帯が出る。スマホ幅（390px）のホスト画面は正式な対応の外で、採点は15〜17点を行き来した。

## まだ確かめていないこと

- 実機（iPhone・Android・TVの内蔵ブラウザ）。自動の試験は Chromium と WebKit（Playwright）だけ。音・振動・傾きの許可・画面ロックでの切断・実際の遅延は、確かめていない。
- 本番の Cloudflare。休止と課金の実際の振る舞いは、公式の文書と計算からの推測（[operate.md](operate.md)）。
- ゲームの音。コンソールの消音の設定をゲームへ伝える仕組みがなく、同梱の4本は音を出さない。
