# この実装が扱う情報は、ニックネームと部屋のコードだけ。保存は部屋が消えるまで

運営者が、自分のプライバシーの説明を書くときの元になる。実装を変えたら、この表も直す。解析・広告・外部への送信は、入れていない（[ADR 0007](../decisions/0007-no-accounts-no-analytics.md)）。

| 情報 | 流れ | 保存 | 消えるとき |
|---|---|---|---|
| ニックネーム | スマホ → Worker → ホストの画面 →（遊ぶとき）ゲームの枠。外部のゲームは、受け取った名前を、その運営者のサーバーへ送れる | 席の一覧として、部屋の保存領域に（再接続のため） | 部屋が閉じるとき。最長12時間 |
| 部屋のコード | 画面と、QRのURLの `#` 以降 | 部屋の保存領域 | 同じ |
| ホスト鍵・再開の札 | 作成時に1回返す | サーバーにはハッシュだけ。ブラウザでは `sessionStorage` | 部屋が閉じるとき、タブを閉じるとき |
| リーダーの席・確認ずみの外部ゲームのホスト名 | ホストのブラウザの中だけ | `sessionStorage`（同じホスト名の確認を、そのタブで1回に抑えるため） | タブを閉じるとき |
| 入力（ボタン・スティック・傾きなど） | スマホ → Worker → ホスト →（遊ぶとき）ゲームの枠。外部のゲームは、入力も、その運営者のサーバーへ送れる | 保存しない。転送だけ | — |
| IPアドレス | Workerが受ける。回数の制限のために数える | 日ごとに変わる塩つきのハッシュだけ。生の値は保存しない（塩は、ハッシュと同じ保存領域にあるので、匿名ではなく、仮名のまま） | UTCの日が変わって最初の作成・照会のときに消える |
| 前回の名前 | スマホのブラウザ | `localStorage` | 利用者が消すまで |
| ゲームの保存 | ホストのブラウザ | `localStorage`（ゲームごとの名前空間、64KBまで） | 利用者が消すまで |
| Cookie | 出さない | — | — |

## 運営の外にある処理

- **ホスティング事業者**（既定ではCloudflare）は、リクエストのメタデータ（IPアドレスなど）を、自分の方針に従って処理する。ログやアクセス分析を有効にするかは、運営者の設定による。このリポジトリの既定では、Workersのログを有効にしていない。
- **外部のゲーム**は、遊ぶときに、そのゲームの運営者のサーバーへ接続する。そのサーバーは、IPアドレスなどを見られる。さらに、ゲームの枠には、参加者のニックネーム・席・入力（傾きの値を含む）が渡るので、ゲームは、それらも自分のサーバーへ送れる。コンソールは、開く前に、ホスト名と、この点を知らせる。運営者は、プライバシーの説明に、第三者（外部のゲームの運営者）への提供として書く。
- **端末のセンサー**（傾き）の値は、スマホのブラウザが許可を得てから、ホストへ送る。保存はしない。

## 前提

名前は、本名ではなくニックネームを前提にしている。参加画面にそう書き、空でも遊べる。個人を特定する情報（本名・連絡先・位置情報）は、画面のどこでも求めない。不適切な名前を自動で止める仕組みは無い。ホストが、その参加者を外す（`kick`）か、部屋の受け付けを締め切る。
