# 既存のゲームの遊びを借りるときの決まり

2026-11-06。市販のボードゲーム・カードゲームの遊びの骨格を借りたゲームを、irori に足すときの線引き。公開資料の整理であり、法的助言ではない。弁護士の確認も受けていない。出典は末尾。

## 借りてよいもの
線は、アイデアと表現の間に引く。借りてよいのは、遊びの規則や仕組みのような、抽象的なアイデアだけ。文化庁は、事実・データ・アイデア・ありふれた表現は著作物に当たらないと説明している。ゲームの画面を争った裁判（知財高判平成24年8月8日、平成24年（ネ）第10027号）でも、アイデアやありふれた表現が共通することは、侵害にならないとされた。

著作権法10条3項（規約・解法に保護が及ばない）は、プログラムの著作物についての定めで、遊びの規則全般にそのまま当てはまるわけではない。線引きは、2条1項1号の「創作的な表現」から考える。

## 借りないもの
名前・ロゴ・絵・札や箱の図柄・説明書の文章と例・世界観・音・書体・画面の動き。商標・意匠・特許は別の話だ。「写していない」でも、問題になりうる。

## 札の構成を1対1で写さない
種類・枚数・効果を市販品と1対1に対応させ、名前だけ置き換える作り方は、適法と断定できない。直接の裁判例が見つからなかった。変えた割合に、安全の基準はない。目的・勝ち方・情報の出し方・手札の動かし方を、自作の考えから設計する。のぞく・入れ替える・守る・指名するのような、札遊び一般の言葉を使うのは構わない。

## 新しいゲームごとの手順
1. 借りた骨格を「何を、どう動かす遊びか」の一文で、仕様に書く。市販品の名前は書かない。
2. 札の名前・文・絵・音は自作する。市販品の札の名前を一式で引き継がない。
3. 元の商品名を、ゲーム名・タグ・「公式」などの表示に使わない。
4. ゲーム名（日英）をWebで検索し、同名・類似名を表にする。重なれば改名する。
5. 商標（J-PlatPat。呼び方や類似名も含め、第9・28・41類など）は、公開前に保守者が確かめる。
6. MIT・Apache-2.0・CC BY 4.0 は、自分が許諾できる部分にだけ付く。他者の権利までは許諾できない。

## 確認の状況（2026-11-06）
| 項目 | 状況 |
|---|---|
| 規則と表現の線引き | 公開情報で整理した（弁護士の確認なし） |
| 札の構成を1対1で写した場合 | 直接の裁判例が見つからなかった。構成から自作して避ける |
| 仮題「ふところの鈴」「Bell in the Sleeve」の同名 | Web検索で同名は見つからなかった。使える保証ではない |
| 商標・意匠・特許（J-PlatPat） | 機械で引けず、未確認。保守者の宿題 |
