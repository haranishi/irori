# 公開して運営するなら、法令の宿題が6つある。個人の無償でも「事業」と判断されうる

手元のWi-Fiで遊ぶだけなら、ここは要らない。公開して続けて運営するとき、運営者が自分で決めたり、確かめたりすることを並べた。条文と資料は2026-10-16に確かめた（出典は [`legal-facts.md`](../../.agent-harness/runs/2026-10-16-bootstrap/research/legal-facts.md)）。弁護士の確認は受けていない。

| 宿題 | 何が問題か | このリポジトリの既定 | 運営者がすること |
|---|---|---|---|
| 1. 第三者のゲームを載せる | 情報流通プラットフォーム対処法。個人規模は大規模事業者の義務（月間発信者1,000万超など）の外。ただし運営者が審査して自分のサイトで配ると、発信者に近づき、同法3条の免責を当てにしにくい | PRで権利を確かめてから取り込む。取り下げの窓口と、7日を目安にした対応 | 連絡先を公開する。申出の本人確認と、権利者かどうかを確かめる手順を決め、対応の記録を残す（業界の著作権ガイドラインに様式がある） |
| 2. 外部送信 | 電気通信事業法27条の12。総務省はオンラインゲームを対象とし、営利でなくても「事業」になりうるとしている | 解析・広告・外部のフォントやスクリプトを入れない。送るのは、役務に必要な情報だけ | 解析などを足すなら、送られる情報・送信先・目的を、通知するか、容易に知れる状態に置く |
| 3. 電気通信事業の届出 | 他人の通信の媒介に当たると、届出が要る。中継が当たるかは未確認 | 運ぶのは、ゲームの操作信号とホストの画面指示だけ。プレイヤー間のチャットはない | 公開して運営する前に、管轄の総合通信局に、仕様（`docs/protocol.md`）を見せて確かめる |
| 4. 子ども | 12歳から15歳以下は、個人情報の扱いに保護者の同意が要る場合がある（個人情報保護委員会 Q&A 1-62） | 名前は任意で、ニックネームでよい。参加画面にも、本名を入れないよう書く。登録は全年齢向けだけ | 個人情報の扱いの説明を書く。問題のある情報への連絡先と、閲覧を防ぐ手順を用意する（青少年インターネット環境整備法） |
| 5. 課金・景品・賞 | 景品表示法、資金決済法、賭博罪。参加料を集めて勝者に配る形は、賭博の検討が要る | 何もない | 付けないのが安全。付けるなら、先に3つの法令を確かめる |
| 6. 規約とプライバシー | 他サイトの規約の丸写しは、複製権の侵害とされた例がある。MITの「無保証」は、消費者契約法の場面では、効かない部分がある | ひな形は用意していない | 自分の言葉で書く。下の項目を決める |

## 規約とプライバシーで、決める項目

提供する内容・禁止すること・登録ゲームの扱いと削除・免責の範囲（故意と重過失は免責できない）・個人情報の種類と使い道と保存期間・外部のサービス（ホスティング事業者）・連絡先・変更の方法・準拠法。定型約款として有効にするには、利用者が見られる場所に示し、同意の手順を置く（民法548条の2）。この実装が扱う情報は [data-handling.md](data-handling.md) にある。

## ひな形を用意しない理由

法的な効果のある文書を、確認なしで配ると、使う人が誤った安心を得る。項目の一覧だけを示し、文面は、運営者の事情に合わせて、運営者が書く。
