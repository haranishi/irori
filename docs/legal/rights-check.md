# 権利の確認の記録：何を・どう調べ・どうだったか・まだ確かめていないこと

公開前に、著作権・規約・商標・個人情報・秘密情報を確かめた記録。「調べていない」を「問題なし」とは書かない。調べた事実の出典は [`legal-facts.md`](../../.agent-harness/runs/2026-10-16-bootstrap/research/legal-facts.md)。法的助言ではなく、弁護士の確認は受けていない。更新日：2026-10-16（公開直前の機械検査の結果は、末尾の表に入れる）。

1. **名前「irori」の商標。** J-PlatPat で「irori」「イロリ」を、区分9・35・38・41・42で検索する。同名の事業者を、Web検索で確認した：株式会社イロリ（東京都、ものづくりクリエイター向けのビジネスSNS「Crafty」を運営、2022年12月設立）、ほかに情報メディアのアプリ「irori」を運営する事業者がある（企業紹介では株式会社アスクリード）。さらに、itch.io に、同名のゲーム「irori」がある（同じゲームの分野）。登録の区分は、いずれも未確認。競合するなら、名前を変える。
2. **任天堂の権利。** 名称・ロゴは使っていないが、ホーム画面の画像意匠や、スマホを操作盤にする仕組みの特許は、J-PlatPat で未確認（取得できなかった）。「Wii U」「Wii」「ニンテンドー」の商標、Wii U のメニューの意匠、操作盤とQR参加の特許を検索する。

4. **弁護士の確認。** 受けていない。
5. **AIの入力に関する設定。** 保守者が使うAIサービスの、入力を学習に使わない設定の確認。
