# 端末とCloudflareの制約は、設計の前提として先に知っておく

2026-10-16に、公式の文書とMDNの互換性データで確かめた。iPhoneのブラウザが持たないもの、切断が日常であること、Cloudflareの課金の数え方が、この設計の出発点になっている。確かめられなかったことは「未確認」と書く。出典つきの生の記録は [`.agent-harness/runs/2026-10-16-bootstrap/research/`](../../.agent-harness/runs/2026-10-16-bootstrap/research/prior-art-and-constraints.md) にある。

## スマホのブラウザ

| 機能 | iOS Safari | Android Chrome | 設計での扱い |
|---|---|---|---|
| 傾き・加速度 | 許可の要求が要る。利用者の操作の中で呼び、HTTPSが必須 | 同じ要求の仕組みが入った。当面は既定で許可 | 「許可する」ボタンを1回押させる。HTTPでは使えない |
| 画面の消灯防止（Wake Lock） | 16.4から。ホーム画面に追加したWebアプリでは18.4まで効かなかった | 84から | 参加のタップの中で取り、`visibilitychange` で取り直す |
| 振動 | 非対応 | 対応。利用者の操作が必要で、別オリジンのiframeの中では使えない | あっても無くても遊べる演出にとどめる |
| 全画面、画面の向きの固定 | どちらも非対応（iPhone） | 対応 | 縦横どちらでも成り立つ配置か、「横にしてね」の案内だけ |
| 音 | 利用者の操作が必要。消音スイッチに従う | 操作のあとに `resume()` | 効果音は大画面で鳴らす |
| マルチタッチ | Pointer Eventsが完全対応 | 対応 | `pointerId` で指を区別。`touch-action` で拡大とスクロールを止める |

## 切断は日常

- Android Chromeは、裏に回ったページを1分で凍結する（Chrome 139から）。Chrome 149からは、戻る/進むのキャッシュに入るときにWebSocketを閉じる。
- iOSは、画面ロックでWebSocketが切れ、通知もないという報告が多い。Appleの公式な説明は見つからなかった（未確認）。
- だから、心拍・再接続・席の復元を、通常の経路として最初から作った（[protocol.md](../protocol.md)）。

## 大画面（ホスト）

PCのブラウザをつないだHDMIが、制約のいちばん少ない形。Chromeのタブキャストは、同じWi-Fiの対応機器へ送れる。TVの内蔵ブラウザ（webOS・Tizen・Silk）は、WebGLとWebSocketの対応が機種と年式で違い、実際の描画性能は未確認。そこで、正式に対応するのはPCのブラウザだけにして、TVは「動けば可」にした。

## Cloudflare（Durable ObjectsとWorkers）

| 項目 | 事実 |
|---|---|
| 休止API | `ctx.acceptWebSocket` で受けると、静かなあいだはメモリから外れ、時間課金がかからない。`setTimeout` や `setInterval` が動いていると休止しない。付属情報は16,384バイトまで |
| 無料プラン | SQLite型のDurable Objectが使える。リクエスト1日10万、時間1.3万GB秒。超えると、その操作が止まり、課金はされない |
| 有料プラン | 超過分は課金される。自動で止める設定は、公式文書に見当たらない。予算アラートは通知だけ |
| 課金の数え方 | DOが受け取るメッセージは20通で1リクエスト（課金の計算）。送信は無料。無料枠にも同じ数え方が効くかは、書かれていない（未確認） |
| 静的ファイル | Workerを通さなければ、無料で無制限。`run_worker_first` で先にWorkerを通すと、枠を使う |
| デプロイ | 全WebSocketが切れる |

数え方が費用を決めるので、スマホは入力を毎秒20回までに間引き、変わらないあいだは送らない。試算は [operate.md](../operate.md)。

## 実機の確認で残っていること

自己署名のHTTPSを押し切ったiPhoneが、傾きを許すか。Quick TunnelでWebSocketが通るか。無料枠での「20通＝1件」の扱い。iOSの画面ロック時の切断の仕様。TVの内蔵ブラウザの描画性能。いずれも、実機か実アカウントで測るまで、「問題ない」とは書かない。
