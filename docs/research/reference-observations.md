# 参考にしたサイトで、観察できたこと

2026-10-16に、着想の元になった既存のWebサイト（`https://vvii.itsu.dev/`、ページのタイトルは「vvii | 驚額の殿堂ファイナル 2026」）を観察した。ここに書くのは事実と、それから分かる設計上の違いだけ。コード・画像・音・文章は取り込んでいない。取り込まない理由と決まりは [legal/reference-policy.md](../legal/reference-policy.md)。

## どう観察したか

- ブラウザで開き、画面の構成と操作の流れを見た。ゲームの中身は遊んでいない。
- スマホ幅の画面で、参加用のURLを1回だけ開き、参加前の画面を見た（1部屋・1接続。操作はしていない）。
- ブラウザに配信される公開のHTMLとJavaScriptから、通信の種類を確かめた。調べたのは、`WebSocket`・`RTCPeerConnection`・`DeviceOrientation` などの語の有無と、その周辺の数行。関数や構造は読み写していない。

## 観察できた事実

| 項目 | 観察 |
|---|---|
| ホームの画面 | 角の丸い横長のタイル（幅と高さの比は、1920×1080で約1.9対1、1366×768で約1.7対1。独立の確認で計測）が12個並ぶ（1ページ12個、次のページへ進むボタンあり）。背景は明るい灰の横じま。下に曲線の帯があり、時計と日付、右下にQRコード、左下に技術同人誌の案内 |
| 参加の入口 | QRコードのURLは、部屋のIDと長い札を `#` 以降に持つ。サーバーのログに残りにくい置き方 |
| スマホの画面 | 最初に「接続する」の1ボタン（端末のセンサーの許可に、ユーザーの操作が要るため）。名前は任意。ボタンは A・B・Home と、傾きの中心を合わせるもの |
| 人数 | 画面の文言から、コントローラーは4台まで |
| 通信 | WebSocketで接続の取り決め（シグナリング）をし、WebRTCのデータチャネル（傾き用・操作用）で送る方式に見える。STUNを使い、つながらないときはWebSocketでの中継に落とす経路もある |
| ゲーム | 画像と音の読み込み先から、サイトに同梱されているように見える（推定） |
| 計測 | 解析のスクリプトと、独自のイベント送信がある |
| 権利の表示 | 利用規約・ライセンス・作者・ソースの場所は、画面にもバンドルにも見つからなかった。Web検索でも、作者のリポジトリは見つからなかった |

権利の表示がないので、すべての権利が留保されているものとして扱う。

## 限界

1回の観察で、2026-10-16の時点の姿。ゲームの中の操作感、遅延、サーバーの実装、費用は、見ていない。通信の「ように見える」と書いた箇所は推定で、確認していない。作者への連絡は取っていない。連絡先が分かれば、着想として参考にしたことを知らせたい。
