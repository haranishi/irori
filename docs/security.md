# 脅威を3つに分けて、守る場所を決める：悪意のあるゲーム、悪意のあるスマホ、費用を狙う利用

誰を信用するかを先に決めた。ホストのブラウザは信用する（ゲーム機の役をする、運営者か本人の端末）。サーバーは信用するが、持つ情報を最小にする。**スマホとゲームは信用しない。** 登録の審査は、保守者が読むが、完全ではない。報告の窓口は [SECURITY.md](../SECURITY.md)。

## 脅威と守り

| 脅威 | 守り |
|---|---|
| ゲームがホストの鍵・画面・ほかのゲームのデータに触る | 隔離した枠で動かす。会話は `MessagePort` だけ。保存は、ゲームごとの名前空間と容量の上限つき（[ADR 0001](decisions/0001-games-in-sandboxed-iframes.md)） |
| ゲームがスマホに不正な表示を送る | 画面は定型7種。文字数・個数・色の名前を上限で縛り、描くときは必ず `textContent` |
| 効果音の依頼が音を鳴らし続ける | 固定23種の合成音だけを受け、SDKと橋で同名50ms・直近1秒20件まで。消音・未解除・前面でないときは捨てる。未知名・範囲外・余分なキーは違反として数える |
| スマホが別の席になりすます | 席番号はサーバーが接続から決める。フレームの `p` は受け付けない。再開の札は128ビットの乱数 |
| スマホやゲームから大量・不正なフレームを送る | 大きさ・速さ・形式をサーバーとホストで二重に検証し、違反が続けば切る |
| 部屋のコードを総当たりする | 約70万通り。`hello` のない接続は5秒で切り、部屋ごとに同時16本まで。存在の確認・接続の受け付け・作成を、IPごとに数える（IPv6は/64と/48）。参加はホストの画面に見え、ホストが外せる・ロックできる |
| 費用や資源を狙う | IPごとの接続と部屋の作成、部屋ごとの新しい席（毎分40）とロックの切り替え（毎分20）、メッセージの速さ、1日の部屋数、寿命に上限。別のサイトのページから、訪問者のIPで部屋を作らせたり接続させたりする要求は `Origin` で断る（[operate.md](operate.md)） |
| 文字列がスクリプトとして実行される（XSS） | `innerHTML` を使わない。CSPは `script-src 'self'`、`frame-ancestors 'none'`、インラインのスクリプトなし |
| ホストの鍵の漏洩 | URLに載せない。ブラウザの `sessionStorage` にだけ置き、サーバーはハッシュだけを持つ |
| 依存の乗っ取り | 配布物に入るnpmの依存は1つ（QRの生成）。日本語の折り返しに使う文節のモデルは、依存にせず、値を写して持つ（[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)）。ActionsはコミットのハッシュでCIに固定、Dependabot、`npm audit` |

## 設計上、防げないもの

- **外部のゲームが、自分のサーバーへ通信すること。** 外部のゲームは、自分のオリジンで動き、ネットワークも使える。コンソールは、開く前にホスト名を知らせ、審査で外へ送る情報の説明を求めるだけ。
- **ホストのブラウザが信用できないとき。** 拡張機能や別のページが、ホストの画面を読めたら、部屋の鍵も読める。
- **外された人が、入り直すこと。** アカウントがなく人を特定できないので、外す（`kick`）と席は空くが、その人が部屋のコードでもう一度入ることは止められない。ホストが部屋をロックすれば止まる。
- **早押しの公平さ。** 受信時刻 `T` は、回線の遅れが違う人の間では、押した順を保証しない。
- **同じLANでのHTTPの盗聴。** HTTPで開くと、部屋のコードと入力は平文で流れる。HTTPSで配れば暗号化される。
- **多数のIPアドレスからの攻撃。** 栓はIPアドレス単位なので、アドレスを多く持つ相手には効かない。無料プランでは、その日の枠（書き込みは1日10万行）を使い切られ、新しい部屋が作れなくなる。課金はされない。有料プランには自動で止める上限がなく、天井の試算は [operate.md](operate.md) にある。大規模なものは、CloudflareのDDoS対策とレート制限の設定に任せる。

## 守りが生きているかの確かめ方

隔離枠の属性、`event.source` の検査、検証、レート制限、接続と入退室の栓、`Origin` の確認、鍵の比較、再開の札の置き換え、猶予の後の席の解放は、**外すと試験が赤くなる**ことを `tools/mutations/` で確かめている。悪意のあるゲームの試験は、実ブラウザで、`parent.document`・`top.location`・`window.open`・フォーム送信・`alert`・`localStorage`・巨大なメッセージの連投を試みる。通ったという記録でなく、壊したら落ちるという記録を守りの証拠にしている。

## まだ確かめていないこと

実機（iPhone・Android）での長時間の動作、TVの内蔵ブラウザ、外部の独立したセキュリティ監査。AIが書いたコードも、読み取りの独立したレビューを通しているが、人の専門家による確認は、受けていない。
