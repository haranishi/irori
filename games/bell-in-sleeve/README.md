# ふところの鈴 / Bell in the Sleeve（仮題）

夜の屋台通りで、金の鈴が誰かのふところにまぎれました。
札の動きと会話を手がかりに、持ち主を探す推理カードです。
3〜8人、推奨5人。1人でもCPUと遊べます。1局の目安は6〜10分です。
人が3人未満なら、合計5席になるまでCPUが加わります。

## 遊び方

1. 進行役のスマホで「はじめる」。自分の手札は、自分のスマホだけで確かめます。
2. 光っている席の番です。札を1枚出し、スマホの案内に沿って相手や位置を選びます。金の鈴は出せません。
3. 手がかりを声で伝えても、黙っていてもかまいません。鈴を持っていたら、平気な顔で逃げ切ろう。
4. 全員が決まった回数を出すと、45秒の言い合い（人1人なら、CPUは話さないため10秒）。人全員が「指名へ進む」を選べば早く終えられます。そのあと、自分以外の1人を一斉に指名します。
5. 最多票の人が持ち主なら屋台側の勝ち。同数や外れは、鈴の持ち主の勝ちです。

## 6種類の札

| 札 | できること |
|---|---|
| 金の鈴 | 出せない1枚。最後の持ち主が鈴の側になる |
| のぞき見 | 相手の伏せた札を1枚、自分だけ見る |
| すりかえ | 自分の札と相手の伏せた札を1枚ずつ取り替える |
| ひそひそ話 | 二人が同時に1枚ずつ選び、相手にだけ見せる |
| つかまえる | 二周目から1人を指名。当たりなら即終了、外れは自分が−1点 |
| かばう | 自分か相手を、その人の次の番が終わるまで「つかまえる」から守る。一斉指名には効かない |

「いまは持っていない」の印は、札が動くと消えます。前の情報を信じすぎないで。
時間切れは合法な手をおまかせで選びます。一時停止中は時計も止まります。
席が退出すると勝負なしで終了します。途中からの参加は次の局からです。

## 得点

つかまえた人は+3点、鈴以外のほかの人は+1点。
一斉指名で見つけたら、当てた人は+2点、外した人は+1点（持ち主は0点）。
逃げ切った持ち主は+4点。外れ指名の−1点は合計に重なります。同点は同順位です。

## 1台で試す

`/games/bell-in-sleeve/?mock=1` で、人1席とCPUの局を遊べます。
`?mock=5` は人5席の仮想コントローラー、`?demo=1` はCPUだけの連続観戦です。
