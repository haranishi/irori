# 大富豪

3〜8人で、手札を先に出し切った順を競う札遊びです。手札は自分のスマホだけに表示され、大画面には場の札と残り枚数が出ます。

## 遊び方

進行役のスマホで「はじめる」を押します。ダイヤの3を持つ人から、席の順に進みます。
自分の番になったら、同じ数の札を1〜4枚選んで「出す」。場があるときは同じ枚数で、場より強い札を選びます。出さないときは「パス」を押せます。

- 通常の強さは3が最弱、2が最強。ジョーカーはいつも最強で、同じ数の代わりにも使えます。
- 8を含むセットは「8切り」。場を流し、出した人がもう一度先に出します。上がったときは次の人へ進みます。
- 4枚のセットで「革命」。3〜2の強さが逆になり、次の革命で元に戻ります。
- 全員が続けてパスすると場を流します。パスした人も、次の番には出せます。
- 手札を出し切った順に上がり。残り1人になると結果を表示し、「もう一度」で新しく配り直します。

接続切れは手札を保ち、その人の番で待ちます。退出すると手札を除外し、順位を付けられる人が2人未満なら勝敗なしで終わります。

## 仮想プレイヤーで試す

ゲームを単体で配信し、`/games/daifugo/?mock=3` を開きます。ゲームフォルダを配信ルートにした場合は `/daifugo/?mock=3` です。`mock=8` で8人も試せます。

1. 1人目の「はじめる」をクリック（またはSpaceキー）。
2. 番の人の仮想パッドをクリックし、札をクリックして選択。「出す」で決定。
3. キーボードは、その席をクリックしてから矢印で移動、Spaceで選択、Enterで決定、Pでパス。
4. 仮想パッドの一時停止・切断も試し、結果の「もう一度」で再戦。

仮想プレイヤーは自動では操作しません。試験用のパッドには各席の手札が出るため、実ホストの共用画面と区別してください。音は仮想プレイヤーでは鳴りません。

札・灯の図形・演出・文言は、このゲーム用に独自に制作しています。音はホストの合成音を使い、画像・音声・書体の外部素材は読み込みません。
