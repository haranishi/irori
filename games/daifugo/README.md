# 大富豪

3〜8人で、手札を先に出し切った順を競う札遊びです。手札は自分のスマホだけに出ます。大画面に出るのは、場の札と残り枚数です。

## 遊び方

進行役のスマホで「はじめる」を押します。ダイヤの3を持つ人から、席の順に進みます。
自分の番になったら、同じ数の札を1〜4枚選んで「出す」。場があるときは同じ枚数で、場より強い札を選びます。出さないときは「パス」を押せます。

- 通常の強さは3が最弱、2が最強。ジョーカーはいつも最強で、同じ数の代わりにも使えます。
- 8を含むセットは「8切り」。場を流し、出した人がもう一度先に出します。上がったときは次の人へ進みます。
- 4枚のセットで「革命」。3〜2の強さが逆になり、次の革命で元に戻ります。
- 全員が続けてパスすると場を流します。パスした人も、次の番には出せます。
- 手札を出し切った順に上がり。残り1人になると結果を表示し、「もう一度」で新しく配り直します。

接続切れは手札を保ち、その人の番で待ちます。退出すると手札を除外し、順位を付けられる人が2人未満なら勝敗なしで終わります。

## 大画面の見方

- 上の段：番の人の名前と印、強さの並び。左が弱く、右が強い。革命中は数の順が逆になり、「革命中」の印が付きます。8には下線。「灯」はジョーカーです。
- 中央の場：直近のセットを大きく出し、その前のセットは薄く後ろに残します。空のときは「先に出す」。
- 下の段：席ごとの残り枚数、パスの吹き出し、順位の札。番の席は、光る枠と「いまの番」の札で分かります。
- 8切り・革命・上がりは、場の上に大きな文字で短く出ます。スマホも震えます。番が来たとき、革命のとき、上がったときです（震えない端末もあります）。
- 動きを減らす設定では、札の移動や裏返しをやめて、短いフェードだけにします。一時停止の間は、動きも止まります。

## 仮想プレイヤーで試す

ゲームのフォルダを配信して `/daifugo/?mock=4` を開きます。リポジトリのルートを配信したときは `/games/daifugo/?mock=4` です。人数は `mock=3`〜`mock=8` で変えられます。

1. Space キー（1人目の「はじめる」）を押すか、1人目の仮想パッドのボタンをクリックします。
2. 番の席の仮想パッドで札をクリックして選び、「出す」を押します。出さないときは「パス」。
3. キーボードでは、その席の仮想パッドをクリックしてから、矢印で移動、Space で選択、Enter で決定、P でパスです。
4. 一時停止・切断も試せます。結果の「もう一度」で配り直します。

仮想プレイヤーは自動では操作しません。試験用のパッドには各席の手札が出るため、実ホストの共用画面と区別してください。音と振動は仮想プレイヤーでは出ません（振動は席の枠が揺れて示します）。

札・柄・灯の図形・演出・文言は、このゲーム用に独自に制作しています。音はホストの合成音を使い、画像・音声・書体の外部素材は読み込みません。
