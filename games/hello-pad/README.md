# ハローパッド：30秒で遊べる、SDKの全体像を見せるいちばん小さな見本

各自の四角がスティックで床を動き、「ぴょん」で一瞬ふくらむ。遊ぶのは30秒。時間切れか、リーダーの「おわる」で全員のゲームが終わり、30秒のあいだの「ぴょん」の回数で順位が決まる。この決まりは遊ぶ前から大画面の上の行に出ていて、いまの回数は各四角の右上に、残りの秒数は画面の右上に出る。終わりをリーダーの手だけに任せていたころは、目指すものがなく、すぐ飽きた。締切はそのためだ。自分のゲームを作るときに最初にコピーする土台で、規則は logic.js に、irori とのやり取りと描画は main.js に分けてある。

## SDKの呼び出しは、main.js の番号の順に並んでいる

1. `connect()` でつなぐ。コンソールの枠の外で開くと、仮想プレイヤーに切り替わる
2. `irori.players` から四角を並べ、`irori.look(席番号)` の色と形で描く
3. `irori.setPad()` で、全員にスティックと「ぴょん」を出す。`irori.leader` の席にだけ `setPad(画面, 席番号)` で「おわる」も出し、リーダーが替わったら（`on('players')` の2つ目の引数）送り直す
4. `on('input')` と `on('players')` を受け、規則が終わり（時間切れ・「おわる」・全員退出）を返したら `irori.end(結果)` を呼ぶ
5. `on('pause')` で動きを止め、`on('resume')` で再開する。30秒の締切は、一時停止のあいだ止まる時計（`createClock`）で測る
6. 最初の画面を描いたら `irori.ready()` を呼ぶ

## ファイルを直接開いても動かないので、HTTPで配る

ES modules は file:// から読めない。リポジトリにある vite で `games/` を配り、`?mock=3` を付けて開く。

    npx vite games --port 5200
    # http://127.0.0.1:5200/hello-pad/?mock=3 を開く。1人目は WASD・Space・E、2人目は矢印・Enter・Shift

規則の試験は `npm run test:games` で流す。

## コピーして自分のゲームにする手順

1. このフォルダを `games/<自分のid>/` に写し、logic.js の規則と main.js の描画を書き換える
2. `npm run build -w @irori/sdk && npm run sync:sdk` で irori.js を写し直す。手で直すと CI が落とす
3. `registry/games/<id>.json` とサムネイルを足す（[docs/registry.md](../../docs/registry.md)）

## つまずきやすいところ（本番の CSP・「おわる」の押し間違い・枠からのはみ出し・途切れる入力・遅れて来た席）

- 本番は `/games/*` を CSP（`default-src 'self'`）つきで配る。HTML の中に書いた `<script>` は動かないので、スクリプトは main.js に置く。vite で開いたときは動いてしまうので、気づきにくい
- 「おわる」を全員に出すと、連打の最中の押し間違い1回で、全員のゲームが終わってしまう。だからリーダーにだけ出し、規則でもリーダー以外の「おわる」は受けない。リーダーが分からないときと、リーダーがこのゲームにいない席のときだけは全員に出す。ボタンで終われなくなるのを防ぐためだ
- 四角が動ける範囲（logic.js の `BOUNDS`）は、ふくらんだ四角と下の名前が床に収まるようにとってある。名前は、ほかの四角に乗らない場所（下・上・右・左の順）へずらす（`placeNames`）。画面の大きさや札の高さを変えたら、試験の「四隅まで倒し続けても」と「8人」で確かめる
- 切断（`online` が偽）は「いま動かせない」だけなので、四角を止めて薄くし、戻れば続きから。席が全部消えたときだけ終わる。途中で席が消えた人も、そのときの回数で結果に載せる（コンソールが「退出」の印を付ける）。スマホの画面は値が変わったときだけ入力を送るので、時間で止める形は dot-grab にある
- 遊べるのは、始めた時点の席だけ（切れていた席も入る）。あとから `players` に入ってきた席は無視する
