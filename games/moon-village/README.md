# 月あかりの寄り合い / Night at Hearth Village

4〜8人で同じ大画面を囲み、言葉と投票で村の行方を決めるゲームです。秘密の役と夜の行動は、自分のスマホだけに届きます。

## 遊び方

1. 進行役がスマホで「はじめる」を押します。全員が「役を見る」で役を確かめ、「かくす」を押すと夜になります。
2. 夜は全員が相手を1人選んで「決定」します。大画面には、決めた人数だけ家の窓の灯が消えていく様子が出ます。だれが決めたかは出しません。
3. 夜明けに発表を読んだら、進行役のスマホの「つづける」で昼へ進みます。
4. 昼は180秒の話し合いです。進行役は「＋1分」で延長し、「投票へ」で早めに進められます。
5. 投票は自分以外の生存者を1人選ぶか棄権します。そろうと、だれがだれに入れたかと票数を公開します。
6. 処刑のあとも、進行役のスマホの「つづける」で次の夜へ進みます。
7. 勝負がつくと、大画面に全員の役と勝った側が8秒ほど出て、そのあと結果画面に移ります。「もう一度」で新しい配役になります。

## 規則の要点

- 人狼がいなくなると村人側、人狼の数が生きている人間以上になると人狼側の勝ちです。狂人は人間として数え、人狼側で勝敗を決めます。
- 初夜は襲撃なし。占い師は1人を占い、騎士は自分以外を守ります。同じ人を2夜続けて守れません。
- 夜は役に関係なく全員が決定します。無効な相手を選ぶと行動なしになり、理由は本人にだけ届きます。
- 最多票が同数なら、同数の人だけで決選を1回行います。なお同数なら処刑しません。
- 夜と投票は、決定が2分止まると未決定を行動なし／棄権として進みます。
- 接続切れや一時停止の間は時計が止まります。戻ったら進行役のスマホで再開してください。
- 退出した人は脱落として続けます。残った参加者が2人未満なら未成立です。

## 大画面の見せ方

- 役は終わるまで大画面に出しません。読み上げ用の文と名前の欄にも入れません。
- 時計は数字と輪の両方で残りを出し、残り30秒で「まもなく投票」に変わります。
- 生死は灯の形（実線と点線）と「生存・脱落・退出」の文字で示し、色だけに頼りません。
- 動きを減らす設定では、移動・点滅・揺れをやめ、短いフェードだけにします。

## 仮想プレイヤーで試す

ゲームを配信する環境で `/games/moon-village/?mock=5` を開きます（4〜8人）。ゲームのフォルダだけを配信する場合は `/moon-village/?mock=5` です。

- 開始：1人目の仮想パッドの「はじめる」をクリックします。
- 役を見る・かくす・つづける：その席の決定（Enter）を押します。
- 札：操作する席をクリックし、矢印キーで動いて Space で選び、Enter で決定します。P は「役を見る」・棄権・延長です。
- 夜明けと処刑のあとは、大画面にも補助の「つづける」が出ます。仮想プレイヤーのときだけです（本物のホストでは大画面を押せないため、進行役のスマホで進めます）。

## 独自の表現

役の名前は一般の言葉を使います。村・月・家・灯・票箱の図形、文、画面構成は、このゲームのために作った独自の表現です。音はコンソールに合成を依頼します。
