# 月夜の村 / Moonlit Village

4〜8人で同じ大画面を囲み、言葉と投票で村の行方を決めるゲームです。秘密の役と夜の行動は、自分のスマホだけに届きます。

進行役がスマホで「はじめる」を押します。全員が役を確認して「かくす」を押したら夜へ。全員が相手を1人選んで決定し、夜明けの発表を読んだら大画面の「昼へ」を押してください。昼は180秒の話し合いです。進行役は「＋1分」で延長し、「投票へ」で早めに進められます。

投票は自分以外の生存者を1人選ぶか棄権します。最多票が同数なら決選を1回行い、なお同数なら処刑しません。処刑のあと、進行役のスマホで「次の夜へ」。結果画面から「もう一度」を選ぶと、新しい配役で遊べます。

## 規則の要点

- 人狼がいなくなると村人側、人狼の数が生きている人間以上になると人狼側の勝ちです。狂人は人間として数え、人狼側で勝敗を決めます。
- 初夜は襲撃なし。占い師は1人を占い、騎士は自分以外を守ります。同じ人を2夜続けて守れません。
- 夜は役に関係なく全員が決定します。無効な相手を選ぶと行動なしになり、理由は本人にだけ届きます。
- 夜と投票は決定が2分止まると未決定を行動なし／棄権として進みます。
- 接続切れや一時停止の間は時計が止まります。戻ったら進行役のスマホで再開してください。
- 退出した人は脱落して続行します。残った参加者が2人未満なら未成立です。

## 仮想プレイヤーで試す

ゲームを配信する環境で `/games/moon-village/?mock=4` を開きます（4〜8人）。ゲームフォルダだけを配信する場合は `/moon-village/?mock=4` です。各席の仮想パッドをクリックして操作できます。

役を見る／かくすは Enter。札は操作する席をクリックしてから矢印キーで移動、Spaceで選択、Enterで決定、Pで「役を見る」や棄権・延長を選べます。開始は仮想パッドの「はじめる」をクリックしてください。夜明けの「昼へ」は大画面のボタンをクリックするか、Tabで移動してEnterを押します。

役の名前は一般の言葉を使い、村・月・灯・札の図形、文、画面構成はこのゲームのために作った独自の表現です。音はコンソールに合成を依頼します。
