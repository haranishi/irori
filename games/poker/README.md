# 持ち点ポーカー / Hearth Poker

夕暮れの縁側で、二枚の手札と五枚の場から強い組み合わせを作る札遊び。
2〜8人、推奨4人。1人でもCPUと遊べます。人が2人未満なら合計4席に補充します。
1局は6ハンド、目安10〜15分です。
**お金・景品は使いません。持ち点はゲームの中だけで、外へ持ち出せません。**

## 遊び方

1. 進行役のスマホで「はじめる」。手札2枚は本人のスマホだけに届きます。
2. 光る席の番です。「おりる」「そのまま」「あわせる」「ふやす」「上限まで」（持ち点すべてなら「ぜんぶ」）から選びます。
3. 残った人の出す点がそろうと、場が3枚→4枚→5枚と開きます。
4. 手札と場の計7枚から、強い5枚で勝負。勝った人が「たまり」を受け取ります。
5. 6ハンド後の持ち点で順位を決めます。同点は同順位です。

持ち点1000から開始。親は毎ハンド交代し、最初に小10点・大20点を順に出します。
ふやす幅は40点・たまりの半分・たまりと同じの3種。押せる行動だけスマホに出ます。
出せる上限は残る席の最小持ち点まで。「ぜんぶ」は自分の持ち点を使い切る場合だけです。完全な同点は等分し、端数は親の次から1点ずつ。
全員がおりて1人だけ残ったら、その人が取ります。おりた人の札は公開しません。
0点になった席は見るだけ。点が残る席が1人になったときも終了します。

## 役の強さ（上ほど強い）

| 役 | 組み合わせ |
|---|---|
| ロイヤルフラッシュ | 同じ柄の10・J・Q・K・A |
| ストレートフラッシュ | 同じ柄で数が5枚連続 |
| フォーカード | 同じ数が4枚 |
| フルハウス | 同じ数3枚と別の同じ数2枚 |
| フラッシュ | 同じ柄が5枚 |
| ストレート | 数が5枚連続（A・2・3・4・5も可） |
| スリーカード | 同じ数が3枚 |
| ツーペア | 同じ数2枚が2組 |
| ワンペア | 同じ数が2枚 |
| ハイカード | 上の組み合わせがない |

同じ役では数の高さ、残りの札の高さを順に比べます。柄の強弱はありません。

## 時間・CPU・席

勝負は公開手札が3席以上なら10秒、2席なら6秒表示します。
結果は最長20秒。人の席全員がスマホの「次へ」を押すとすぐ進みます。
1手25秒。時間切れは「そのまま」が可能ならそのまま、それ以外はおりる。
接続切れも時間で進み、一時停止中は時計とCPUが止まります。
退出した席はおりて局を続け、人が全員退出した場合は勝負なしで終了します。
CPUは「ふつう」。自分の手札と公開された情報だけを見て考えます。
CPUを含む局は、結果に「N位(CPUこみ)」と出します。
`?mock=1` は人1席とCPU3席、`?mock=4` は人4席。`?demo=1` はCPUだけの連続観戦。
