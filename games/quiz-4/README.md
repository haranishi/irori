# 4択クイズ：問題ごとに choices を差し替え、答えた人から押せなくする見本

全8問、1問15秒。正解は早いほど高く、1000点から200点まで直線で下がる。まちがいと時間切れは-200点。questions.js の26問から重ならずに8問を選び、前の2回に出た問題は、足りるかぎり避ける。終わり方は2つ（8問を終える・全員退出）で、logic.test.js がどちらも end まで通している。

## 使っているSDKの機能

問題ごとに `choices` を差し替える `setPad`、答えた人だけに `disabled: true` を送る席ごとの `setPad`、出した問題を覚える `storage`。画面は canvas でなく DOM で描き、文字はすべて textContent で入れる（長い問題文の折り返しと、読み上げのため）。

## 締切ちょうどの回答は受けず、切れている人は減点しない

- 締切ちょうど（出題から15000ms）の回答は受けず、時間切れの-200点にする。境界の1ms前後を試験している
- 答えたら、その人のスマホの選択肢を押せなくし、ヒントに「あなたの答え：…」を出す。押し直しはできないので、始める前の説明に書いてある
- 一時停止のあいだは時計を止め、回答も受けない。そのぶん締切が延びる
- 切れている人（`online` が偽）は待たずに締め切り、その問題は0点にする（減点しない）。締切の前に戻れば答えられる。参加者から外すのは、席が `players` から消えたときだけ。消えた人の札は「退出」にして点はそのまま見せ、結果にも抜けたときの点で載せる（4本でそろえている）
- 答え合わせで選んだ人の印は、答えの下の行に並べる。答えと同じ行に置いていたころは、8人が同じ長い答えを選ぶと、文字が折り返して枠の上下にはみ出した
- 覚える問題は「問題の数 − 8」（26問なら18問）。直前の1回だけを避けると、1回おきに同じ問題が出やすかった
- `storage` は、単体で開いた隔離枠では使えない。0.8秒で答えがなければ、前を避けずに選ぶ

## 問題を足すときの決まり

questions.js に自作の短い文で足す。選択肢は12文字以内（11文字からは字を小さくして1行に収める）で、正解は1つだけにする。2つの県を答える問題では、誤りの選択肢に正解の県を混ぜない（紛らわしすぎるため。試験が見張っている）。答えの事実は信頼できる資料で確かめ、`src` と下の出典に書く。確かめられない問題は入れない。実在の企業名・個人名・商標は、問題文にも選択肢にも使わない。
