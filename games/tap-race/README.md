# 連打レース：早押しの順番と締切と途中退出を、3つの終わり方まで通す見本

3・2・1の合図で `buzzer` を40回たたき、早く完走した順に点が入る（1位から800・600・500・400・300・200・100・50）。1回もたたかなかった人と棄権した人は0点で、何もしないで点が入ることはない。終わり方は3つある。全員完走、30秒の時間切れ、全員退出。logic.test.js が、3つとも end まで通している。

## 使っているSDKの機能

席ごとに画面を出し分ける `setPad(画面, 席番号)`（「よーい」と完走後は `wait`、レース中は `buzzer`）。合図と完走の `vibrate`。退出を知る `on('players')`。そして `on('input')` の3つ目の引数 `T`。

## 順位はサーバーの時刻 T で、締切はゲームの時計で決める

完走の順位は、入力に付くサーバーの受信時刻 `T` の順にする。ホストに届いた順より安定するためで（docs/sdk.md）、T が同じなら同じ順位にする。一方、30秒の締切と結果に出す秒数は、一時停止のあいだ止まる時計（logic.js の `createClock`）で測る。T はサーバーの時計なので、ホストの時刻と引き算しない。

締切ちょうど（スタートから30000ms）の連打は数えない。境界の1ms前後は試験で押さえてある。

## 切断は「いま押せない」だけ。席が消えたときだけ棄権にする

スマホの切断画面は「つながったら、そのまま続けられます。」と約束している。だから `online` が偽になっても棄権にせず、回数を保つ。戻れば続きから押せる。棄権にするのは、席が `players` から消えたとき（猶予切れ・退出・外された）だけだ。始めた時点で切れていた席も走者に入れる。

全員完走は、まだ席にいる人で判定する。切れている人は、戻るか30秒の締切が来るまで待つ。棄権した人も、完走したあとで退出した人も、結果に残す（棄権は「棄権」の0点）。コンソールは抜けた人の名前を控えていて、結果に「退出」の印を付ける。席が全部消えたら「全員退出」で終わる。あとから来た席には、ゲームからは何も送らない（待機の画面はコンソールが出す。docs/ux.md）。

## 改造するときに気をつけること

- 回数・秒数・得点表は logic.js の先頭にある。得点表 `POINTS` は、最大人数の8つぶん用意する
- 連打の画面は、押した瞬間に `d:1`、離すと `d:0` を送る。数えるのは `d:1` だけにする
- 一時停止のあいだの入力は main.js で捨てている。時計が止まっているので、数えると不公平になる
