# せーので10秒

2〜8人で遊ぶ、10秒の感覚を競うゲーム。大画面の合図から数え、10秒だと思ったら各自のスマホで1回押す。

## 遊び方

1. iroriの共用画面のQRから、各自のスマホで参加する。
2. 棚で「せーので10秒」を選び、進行役がスマホで「はじめる」を押す。
3. 大画面の「3・2・1・せーの」で数え始め、自分の10秒で「10秒！」を押す。
4. 全員の記録が一斉に出る。結果を見て、進行役が「次へ」を押す。
5. 3回の合計のズレが小さい人が勝ち。同じズレなら同順位。「もう一度」で新しい勝負を始める。

記録は0.1秒単位に丸めてから採点する。時間切れは実測の秒数を付けず、採点用のズレを10.0秒とする。
計測中は、他の人が押したかどうかも表示しない。音・振動は使わない。
通信の遅れを含む目安です。競技用の正確さを保証するものではない。

## 中断したら

切断や一時停止では、その回だけをやり直す。前の回の記録は残る。
つなぎ直しを待ち、戻ったら進行役の「やり直す」で再開する。復帰だけで自動的に数え始めない。
退出した人の途中記録は残すが、順位の対象から外す。2人未満になった勝負は勝敗なし。
途中から来た人は次の一勝負から参加する。大画面の再読み込みはホームへ戻る。

## 1台で試す

開発中のコンソールで `/games/ten-seconds/?mock=2` を開くと、仮想プレイヤー2人で試せる。
1人目のボタンはSpace、2人目はEnter。画面脇のパッドも使える。スマホ接続の検証とは別の試し方。
作り方とSDKの追加機能は [SDKの文書](../../docs/sdk.md)、判定の契約は [詳細設計](../../.kiro/specs/ten-seconds-party/design.md)を参照。
